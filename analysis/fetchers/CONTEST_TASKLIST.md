# 征文采集 tasklist

> **用途**：征文爬虫的采集进度清单。每采完一个赛事（roster + dedup + details 三步跑完），
> 把该行 `- [ ]` 改成 `- [x]` 并在行尾补采集日期与新书数。
> **排序**：按赛事启动时间**降序**（新→旧）。tagId 是全局递增号池（`docs/contest-roster-harvest.md` §5），
> 无显式日期的独立赛事用 tag 号近似定序，有官方日期的以日期为准。
> **采集命令**：`uv run python analysis/fetchers/harvest_contest.py --step all --tags <该行tag>`，
> 全部赛事可用 `--tags all`。**tag 真值**在 `contest_harvest_targets.json`，本文只记进度、不维护 tag 事实。
> **无 API**：一/二/三征（页面下线或参赛展空，用户 DevTools 实证），不在表内。
> **口径**：赛事年份/启动日期为快照值、仅用于排序，随数据版本变化；禁止硬编码进代码。
