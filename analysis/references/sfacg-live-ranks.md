## 1. 端点实测结果

| 端点 | 认证 | 结果 |
| --- | --- | --- |
| `book.sfacg.com/Rank/` | 无 | **可用**。一页含 4 榜：月度月票（**带票数**）、月度打赏、月度热销、粉丝榜（读者侧，消费火券）。条目 URL 含 nid |
| `m.sfacg.com/rank/{original,bm,new,jp,sale}.html` | 无 | **可用**（curl 直抓）。人气/收藏/新书/日轻/热销，各 top 20，无数值，nid 在相对链接 `/b/{nid}/` |
| `m.sfacg.com/rank/ticket.html` | 无 | JS 渲染，curl 拿不到（用 web 版替代） |
| `m.sfacg.com/API/HTML5.ashx?op=search&keyword={kw}` | 无 | **可用**。JSON，固定 ~12 条，含 `NovelID`/`Point` 评分/`TypeName`（参数名是 `keyword`，`q`/`key`/`s` 均报 501） |
| `pages.sfacg.com/ajax/act/MonthlyBoy.ashx?op=getRanks&date={YYYY-MM}&rank={N}` | 无 | **可用，且可查任意月份（历史月票库）**。rank: 0=月票榜(top20, ticketNum=月票)、2=新书榜(top10)、3=热销榜(top20)、4=对话月票榜(top20)；rank=1 为 novly 未收录的未知榜。**2013-03 起连续有数据**（2013-02 及更早实测为空），每月一期、月度清零。语义证据：temp/novly/utils/{monthlyApi,urls,months}.ts + app/monthly/[ym].tsx。抓取器：`analysis/fetch_monthly_ranks.py` → `out/monthly_ranks.jsonl` |
| `api.sfacg.com/novels/{nid}?expand=...,ticket,...` | Basic（`SFACG_AUTH`） | 本机无认证串，未测。单书月票（含周/月）只能走此端点 |

### 关键观察

1. **商业榜（月票/打赏/热销）约一半上榜书 nid > 774,850**——快照（2026-05-03）
   之后创建的新书占据当期商业头部一半席位。商业化是「现役新书」的游戏。
2. **上榜即商业化**：在库的月票榜/热销榜条目 100%（18/18+2/2）为 VIP 或签约，
   免费（原生付费免费层）0 本。与报告 03/06 的 VIP 门槛线索互相印证。
3. **人气榜头部被 2020 世代整体霸占**：top20 定年全部落在 2020 年（nid 397k–407k
   连续窄带）。当期人气 ≠ 当期新书；2020 世代仍是站内人气的存量头部。
4. **热销榜横跨 2016–2026 十个年份段**：《武林之王的退隐生活》（55564，2016）、
   《在充满怪谈的世界里成为魔女》（292551，2017 段）等完结老书仍在月度热销榜
   ——直接反驳「完结书商业价值清零、撤榜」的旧叙事（docs/data-findings.md §7
   那条机制描述基于人气榜位快照，与月度热销榜的真实行为不符）。
5. 收藏榜/新书榜几乎整体超出快照上界 → 「当期收藏增速」集中在最近几个月的新书。

## 4. 使用规则

- 本文件所有数字为 2026-11-16 单次快照，月票/打赏/热销为**月度口径**（按月清零）；
  人气/收藏/新书为**当期口径**（15 分钟至滚动刷新）。
- 与 novels.csv 的任何对比都是**跨时点对照**（数据集 2026-05-03 vs 榜单 2026-11-16），
  引用结果时必须声明两个时点。
- 月票票数是站内唯一公开的付费强度信号（vs `fireMoney` 是定价不是销量），
  但 n=20 且月度清零，只作画像/佐证，不作回归样本。
