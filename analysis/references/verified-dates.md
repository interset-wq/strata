# 外部核实的创建时间（定年独立校验集）

> **来源**：用户于 2026-11-16 分批提供，口语化消息，非公开网页；未附取证 URL、接口响应或截图。
> **性质**：全部为 `exact` 精确创建日期（等式约束）。最初 3 条以「粗略」口径提供（自述误差 <7 天、约 80% 为准确值），2026-11-16 经用户确认为准确时间，升级并入本集；`anchors/approximate_dates.jsonl` 随之清空（文件保留，备后续粗略日期）。
> **数据文件**：`anchors/verified_dates.jsonl`（12 条 exact），追加式 UTF-8。
> **用途**：回测 `analysis/eras.py` 的 nid 定年偏差，作**独立校验集**，不参与插值。
> **读取**：`eras.load_verified()`；报告 01 §1 现算偏差表。
> **注意**：除「一、用户提供的原始信息」外，其余核对、配对与推断均为整理者注。

## 二、配对判定（整理者注）

首批消息中**书名按 nid 从新到旧列出、日期按时间从早到晚给出**，二者不是逐项对应：

| 配对 | 规则 | 结果 |
|---|---|---|
| A（采用） | nid 与日期单调递增对应 | 偏差 **0 / +24 / −1 天**，落在置信分档误差量级内 |

## 四、low 段误差实测（8 点全精确，整理者注）

low 置信段共 8 个外部校验点，全部为用户确认的准确创建时间（其中 3 条最初以「粗略」口径提供、后经确认升级，见 §一）：

| 区间 | 校验点（nid） | 偏差（天） | 方向 |
|---|---|---|---|
| 2012 段（nid 16,871 → 29,547，间隔 668 天） | 3（24719 / 26697 / 27454） | −57 / −50 / −28 | 全负：定年偏晚 1–2 个月 |
| 2015–16 段（nid 29,547 → 61,157，间隔 870 / 478 天） | 5（40723 / 42229 / 42842 / 48704 / 55564） | +5 / +13 / +18 / +36 / +76 | 全正：定年偏早 1–2.5 个月 |

这是 low 段定年误差的首个定量实测，且已从「方向不一致的随机误差」升级为**段内方向一致的系统性模式**：参考日均为准确时间，偏差只能来自插值本身，提示 low 段 log(nid) 插值的局部斜率存在可修正偏差。870 天间隔内三点残差 ≤18 天，该段插值近似线性但整体偏早。这与「该区间年份误差可达数月」的既有声明一致；年粒度比较在跨年边界放大小误差的现象也由此解释（《我是高富帅》史料「+1 年」实为创建 2012-12-12 与定年 2013-01-09 之间的 28 天）。

是否据此做 low 段局部重标定**待定**（量化影响见 §七第 1 条），默认不并入。

## 五、封面时间戳机制的修正（整理者注，用户口述）

用户指出：`featured=1` 的非日轻换封面较频繁，**banner 更新后一段时间封面会由平台同步更新，操作方是平台而非作者**。因此运营位书的 `cover_url` 时间戳记录的是运营操作，不是作品创建，不能作定年证据。

分层实测（偏差 = 封面时间戳 − nid 定年，样本为共用封面清洗后的属主封面）：

| 分层 | n | 中位 | P5 / P95 | ±47 天内 | 晚于 365 天 |
|---|---:|---:|---|---:|---:|
| 全部 | 106,152 | −11 天 | −29 / +233 天 | 88.84% | 3.47% |
| `featured=0` | 106,081 | −11 天 | −29 / +231 天 | **88.90%** | 3.44% |
| `featured=1` | 71 | **+338 天** | +118 / +1537 天 | **0%** | 46.48% |

运营位组与用户描述完全吻合（无一本落在 ±47 天窗口内）。据此对报告 01 §1 作两处修正：

1. 封面验证**剔除 `featured=1`**，样本 106,152 → 106,081；`01_dating.png` 同步改为非运营位分布。
2. 修正一处口径错写：原文「两条证据链在 ±47 天内吻合的占 97.7%」实际是 `100% − 早于 31 天违例率`，只罚提前、不罚滞后，不是双侧吻合率。**双侧 ±47 天吻合率为 88.9%**。

仍需注意：`featured` 是快照当前态，banner 已撤下的书 `featured=0` 但封面可能仍是运营期换过的，构成非运营位组右侧长尾（3.44% 晚于一年）。因此封面时间戳一般只能给出创建的弱下界，**不可逐本反推上架日**。

本文件 12 本 exact 作品全部 `featured=1`，其封面一律不可用于创建时间交叉验证。

## 六、不可用旁证（整理者注）

- **封面时间戳**：619932 / 677177 的 `cover_url` 因共用封面清洗置空，730611 的封面路径为 `2026/01/…`（最后一次换封面）；其余九本全部 `featured=1`，按 §五机制封面均不可用。
- **`updated_at`**：619932 与 677177 分别为 `2024-12-27T19:15:42` 与 `19:15:21`（相隔 21 秒），是批量操作而非创建时间；730611 为 `2026-05-03T00:30:02`。第三本创建日 `2024-12-27` 恰与前两本更新时间同日，属巧合，**不构成 `updated_at` 可作时间轴的证据**。

## 七、口径边界（整理者注）

1. **不并入 91 个 API 插值锚点（重估后仍维持，重标定待定）**。按 12 条 exact 全部并入模拟（91+12 锚点）：全库 **32,232 行（13.11%）** 定年变化（偏移 −58 至 +77 天、中位绝对偏移 10 天），其中 **2,336 行跨越年度边界**；分段偏移与 §四偏差模式方向一致——2012 段 6,085 行（−58..−1，全负）、2015 段（29547–43303）5,944 行与 2016 段（43303–61157）6,112 行（+1..+77，全正）、扩张期 0 行、2023–24 段 14,091 行（−3..+25）。系统性偏差的量级仅 1–2.5 个月，且证据未附可复核来源；并入还会改变 `eras.leave_one_out()` 误差口径并连带改变三份报告的年度统计。**重标定与否由用户决定，不自动并入。**
2. **样本非独立、n 小**。12 本中 3 本同作者、同征文系列且需配对判定；8 本 low 段作品全为头部 VIP 运营位作品（favs 1.1 万–28.1 万）；全部同日由同一用户核验。价值在**绝对日期的等式级回测**，不可用于推断全库分布或误差分位。
3. **证据强度不对等**。91 个 API 锚点来自站点 `addTime` 实测且可复现；本组为用户核验结果，未附可公开复核来源，首批配对还依赖推断（虽有两重佐证）。取得 URL / 接口响应后应把 `source` 从 `user_verified` 改为具体来源并存档原始响应。
4. **三类外部日期不可混写**：`anchors/wayback_anchors.jsonl`（拟）存快照**上界**、`verified_dates.jsonl` 存 `bound_type=exact`、`approximate_dates.jsonl` 存 `bound_type=approximate`（现已清空，文件保留备后续粗略日期）。上界不是等式约束，不能与后两类一同并入插值。
