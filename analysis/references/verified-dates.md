# 三本作品的精确创建时间（定年独立校验集）

> **来源**：用户于 2026-11-16 提供，口语化消息，非公开网页。
> **性质**：作品创建时间的**精确日期**（等式约束），强于网络时光机快照只能给出的上界。
> **数据文件**：`analysis/anchors/verified_dates.jsonl`（3 条，追加式，UTF-8）。
> **用途**：回测 `analysis/eras.py` 的 nid 定年偏差，作**独立校验集**，不参与插值。
> **注意**：本文件除「用户提供的原始信息」一节外，其余核对、配对与推断均为整理者注。

## 二、配对判定（整理者注）

消息中**书名按 nid 从新到旧列出，日期按时间从早到晚给出**，二者不是逐项对应。存在两种可能的配对：

| 配对 | 规则 | 结果 |
|---|---|---|
| A（采用） | nid 与日期单调递增对应 | 偏差 **0 / +24 / −1 天**，全部落在置信分档误差量级内 |
| B（排除） | 按消息中书名与日期的列出顺序逐一对应 | 偏差 **−700 / +24 / +699 天**，与 nid 递增矛盾 |

配对 A 另有两条独立佐证：

1. **同作者连续序列**：三本作者均为「漢唐歸來」，题材均为魔幻、均为 VIP、均为 `featured=1`，nid 619932 → 677177 → 730611 依次递增。
2. **征文届次逐年对应**：三本分别挂「第六届 / 第七届 / 第八届冬季征文」。各届参赛作品的 nid 定年主体区间依次为 2022-12–2023-02、2023-12–2024-03、2024-12–2025-02（详见下节），届次与日期同步递增。若采用配对 B，则届次与年份顺序完全错乱。

**结论**：配对 A 是唯一自洽解释。若用户后续确认原始对应关系不同，需撤回本文件与报告 01 §1 的第四条证据链。

### 两条不可用的旁证

- **封面时间戳**：619932 与 677177 的 `cover_url` 因共用封面清洗规则置空；730611 的封面路径为 `2026/01/…`，记录的是最后一次换封面。三本均无法用 `cover_timestamp()` 交叉验证创建时间。
- **`updated_at`**：619932 与 677177 分别为 `2024-12-27T19:15:42` 与 `19:15:21`（相隔 21 秒），是批量操作而非创建时间；730611 为 `2026-05-03T00:30:02`。第三本的创建日期 `2024-12-27` 恰与前两本的更新时间同日，属巧合，**不构成 `updated_at` 可作时间轴的证据**。

## 四、口径边界（整理者注）

1. **不并入 91 个 API 插值锚点**。实测模拟：将 3 条作为等式锚点加入后，全库 **8,946 行（3.64%）** 定年发生变化（nid 607,446–731,492，偏移 −1 至 +25 天，中位 6 天），其中 **1,205 行跨越年度边界**。并入将连带改变报告 01/02/03 的全部年度统计与 `eras.leave_one_out()` 的误差口径；且三条偏差无一致方向，不存在必须修正的系统性偏移。故本次只作校验集。
2. **n = 3，非统计样本**。三本同作者、同题材、同征文系列、同为头部 VIP 运营位作品，选样不独立；其价值在于**绝对日期的等式校验**，不可用于推断分布、误差分位或全库偏差。
3. **证据强度不对等**。91 个 API 锚点来自站点 `addTime` 实测且可复现；本组为用户核验结果，未附可公开复核的来源，配对还依赖推断（虽有两重佐证）。因此它与第三条证据链（北大《编年简史》7 部代表作，校准 2012–2016 low 段）互补：本组首次把**等式级**独立校准覆盖到 2023–2024 的 high/mid 段。
4. **与 Wayback 计划的关系**：此前约定的 `anchors/wayback_anchors.jsonl` 用于存放快照**上界**。本组是精确日期，故另立 `verified_dates.jsonl` 并以 `bound_type=exact` 区分，两类不可混写。

## 五、后续取证建议（整理者注）

三本恰好是同一作者连续三届冬季征文的参赛作品，说明**征文公告页 / 参赛作品列表**是批量获取精确创建时间的高效来源（一次页面常含数十至数百本，且届次提供天然年份约束）。若取得可复核的征文页 URL 或接口响应，应把 `source` 字段从 `user_verified` 改为具体 URL 并附原始响应存档，再把本组证据等级提升。优先补 2010–2016 low 置信段。
