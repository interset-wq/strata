# APP 设计文档 03：榜单与分位排序

> **定案 v1.0**。口径依据：`analysis/` 报告现算；参照
> [novly](https://github.com/light-nook-labs/novly) 仅作取舍对照，不复用其代码。
> 分位字段、候选池、查询约定已在 02 落定。
>
> **E.30 变更（2026-11-24）**：四个 universe 分位列不再随种子携带（schema v9，见 02）。
> 同代榜单排序 = 同 `est_year` 内 `favs DESC`（同代内与分位序单调等价，榜序不变）；
> 跨代榜（新书榜/赛事代表作/作者代表作/roster 降级）以 favs 近似，文档注明。
> 分位**展示**退役；分位**判定**（构建期选种/优质判定）不受影响。

## 0. 结论

榜单三类数据源，**不可混排、不可同页比较**：

| 类 | 候选池 | 时间基准 | 网络 | 榜单 |
| --- | --- | --- | --- | --- |
| A 离线种子榜 | 种子 18,750 本（正版 47 只进检索不进 A 类） | 2026-05-03 快照 | 否 | 同代 favs/比率/结构/时间/历史月榜/短篇榜 |
| B 在线官方榜 | 全站当月 | 实时 | 是 | 月票/热销/对话月票 |
| C 端上观测榜 | 本机见过的书 | 本机观测 | 否 | 收藏涨幅榜（唯一） |

不可协商规则：
1. （E.30 退役）原「A 类成绩标注"分位"」不再适用：分位展示退役，同代榜标注「同代收藏降序」，绝对数即主排序键；
2. A/B 分区呈现，各自标注候选池与时间基准；C 独立入口；
3. C 类样本不足时**隐藏整榜**，不做降级展示；
4. 短篇榜专属刻度（§4.7）；
5. A 类查询必须带 `is_licensed=0`，详情页明示「正版引进，不参与历史分位」。

## 1. 成绩口径

| 指标 | 字段 | 可比性 | 用法 |
| --- | --- | --- | --- |
| clicks | 累计，曝光分母+书龄混杂 | 分位为主，须分曝光档 |
| favs | 比点击更接近真实偏好，仍有书龄效应 | 分位为主 |
| praises | 绝对数不可比 | 仅用赞藏比 |
| words | 篇幅非成绩 | 独立展示，不与成绩并列成榜 |
| est_year | 定年结果 | 分位分组键 |

两个已核实前提：当前数据**无显示值截断**（`favs` 上限 353,958 为自然长尾；
旧数据集 9,999 截断缺陷不适用）；上游无评论数字段，全库长评/短评榜**不可做**
（观测列表内的单书评论曲线可行，归 07）。

## 2. 为什么必须分位

绝对榜系统性屏蔽早期世代（现算）：全库 favs top20 里 **2007–2014 一本没有**、
2020–2022 占 40%；2010 世代冠军全库仅第 1,288 名。分位榜让每个世代都有代表作。

但**分位不是排名**：它是组内相对位置，跨组不可比——2010 与 2018 的分位冠军都是 1.0，
绝对收藏差 20 倍。展示规则：分位用文字+档位（"同世代前 5%"）；需要"谁更强"给同世代
排序；绝对排名可作附加信息但必须与分位并排并注明不可比。

## 3. 分位设计

- **构建期计算**（E.30：四个分位列不再随种子携带——只能在全 universe 上算、
  端上不可重算、无 user.db 镜像；定义保留供构建期选种/优质判定/深榜 `pctl` 列）。
  `pr` 是唯一随种子的比率列（预计算 + 索引）。
- **参照系是全库**（`is_licensed=0` 且 `est_year∈2007–2025`，241,864 行）按 `est_year`
  分组，不是种子池——池内算分位会被筛选动作改分母，全库分位则「同世代前 5%」
  在任何候选池里都成立。2026 年书（右删失）与正版日轻不进分母。
- **`pr` 必须预计算**：现算 44.9ms，预计算列+索引 0.056ms（800×）——不做预计算就没有比率榜。

## 4. 榜单清单

### 4.1 A 类离线榜

| 组 | 榜 | 排序键 | 约束 |
| --- | --- | --- | --- |
| 分位榜 | 世代收藏/点击/字数分位、世代收藏份额、题材内分位 | 组内分位 | 点击须分曝光档；字数独立成榜 |
| 比率榜 | 赞藏比榜、点击转化率榜、完结率榜、断更率榜 | `pr`/`favs/clicks`/聚合 | 赞藏比 `favs≥10`；**转化率必须按曝光档分层** |
| 结构榜 | 题材/标签供给榜、标签供需错配榜、作者榜、征文榜 | 计数/聚合 | 各自独立，不做 facet 交叉矩阵（v1 不做） |
| 时间榜 | 断更时长榜（不依赖定年）、完结时长榜（依赖定年，低段符号翻转）、新作榜 | — | 新作榜优于官方新书榜（官方按月清零且数据稀疏） |
| 历史月榜 | 165 个月（2013-03 起）× 月票/热销/对话月票，离线回溯 | — | `out/monthly_ranks.jsonl` 1.9 MB 随种子打包；**不做官方新书榜产品化**（中位 0 条/月） |

### 4.2 B 类在线官方榜

`MonthlyBoy.ashx` rank 0/3/4（月票/热销/对话月票）：热销 `ticketNum` 恒 0 只显名次；
每月清零、top20 右截断，只作结构描述；缓存 24h；与 A 类分区。

### 4.3 C 类观测榜

**只有收藏涨幅榜**。点击变化不做——不是精度问题，是**排行式跨书比较需要曝光分母
分档**（累计量口径），端上没有分母；App API 精确整数让**单书曲线**成立（07），
但跨书榜仍不做。依赖 `observations` 累积（05），成熟阈值待实测。

与 07 作者工作台分工：C 类=读者侧排行（本机全部观测书、仅 favs）；
工作台=作者侧仪表盘（`watchlist` 书、全指标+复合指标、热力图+对照图、可订阅）。
共用数据源，不混页。

### 4.4 短篇榜（A 类专项）

短篇定义 `words ≤ 50,000` 且 `status='已完结'`。三个硬约束（报告 19）：

| 约束 | 数据 | 含义 |
| --- | --- | --- |
| 收藏天花板 | ≤5 万字收藏上限 7,881，过万 0 本 | 跨品类比收藏无意义 |
| 赞藏比方向反 | 同字数×完结档内 pr-top5% 收藏中位 2.1 vs pr-bot5% 22.1 | 比值指标在低曝光下失效，禁用于短篇排序 |
| 转化率是伪信号 | cvr-top5% 的 clicks 中位仅 50 | 转化率榜排出"没人看但被极少数收藏"的书 |

榜单：短篇收藏榜（`favs` 绝对值**限集合内**，集合内书龄影响弱）、
短篇分位榜（字数档×世代双组分位）、短篇题材榜（口碑层 60.5% 是同人，不复用长篇体系）。
官方"短篇"赛项标签只作徽章**不作排序键**（赛项书收藏中位低 40–60%）。

查询约定（02 §2.2 实测）：必须走部分索引 `idx_shortfav`（通用索引扫 2.7 倍，15.1ms
比无索引还慢；部分索引 0.045ms）。跨代查询必须按代分别查询再合并
（`est_year>=2024` 整体过滤会选错索引，0.578→0.047ms）。

## 5. 展示红线

1. 成绩榜默认分位，绝对数辅助，参照系同屏标注；
2. 字数不与成绩并列成榜；
3. A 类每页标注候选池范围与快照时间，不出现「全库第 N 名」；
4. A/B/C 分区，不跨类排序；
5. 不可比处显式标注：跨世代不可比、2022 词表断层、遗漏按 nid 段非均匀（覆盖率 69.3%
   是可访问上界）；
6. 标签榜标注词表版本；萌神类荣誉标签不进统计。

## 6. 对照 novly 的取舍

绝对数榜 → 改造为分位榜；长评/短评全库榜 → 不可做（无字段）；完本随机推荐 →
改为完结时长榜；在线月票/热销/对话月票 → 沿用、去新书榜；月份历史回溯 → 我们独有；
"猜你喜欢" → 以 C 类观测榜替代（novly 弃用原因与报告 02/08 一致）。

## 7. 不做

全库长评/短评榜；官方新书榜产品化；全局绝对成绩榜；跨 A/B/C 混合排序；
端上实时全库榜；基于 `updated_at` 的入库年筛选（必须走 `est_year`）。

## 8. 待决

C 类成熟期阈值 N 待实测；在线榜入口位置随 UI 定。
