# 16 · UI 模式登记（UI Pattern Registry）

> 目的：① **UI 多样性**——同类交互在不同页面尽量不重复用同一控件，避免整 App 模板感；
> ② **术语学习**——新增页面时先查本文找模式名字，再登记使用处。
> 分工：docs/15 管「语义 → icon」（同一语义任何页面同一个 icon）；本文管「场景 → UI 模式」。
> 本文与 docs/08（引擎 API）、docs/12（双模式契约）同级，是 UI 层的约束文档。

## 规则

1. **多样性规则**：两个页面做「同一类交互」（切轴 / 筛选 / 选择 / 列表分页）时，
   尽量选用**不同的**模式；同一页面内的同类交互保持自身一致。
2. **登记规则**：页面上首次使用某模式前，先在「现用登记」加一行（模式 + 页面 + 选择理由）。
3. **选型规则**：先查「选型速查表」按选择规模 / 任务类型定候选；两个候选都合适时，
   选当前 App 还没用过的那个。

## 选型速查表

| 场景 | 候选模式（按优先） |
| --- | --- |
| 2–4 个互斥选项 | Segmented Control（分段按钮） |
| 5–15 个短词选项（可换行） | FilterChip 标签行 |
| 15–50 个选项、需要搜索 | Drawer（侧滑面板） |
| 15–50 个选项、是"当前动作的参数" | Modal Bottom Sheet（底部抽屉） |
| >50 个选项 | 独立搜索列表页 |
| 列表 >一屏 | Infinite Scroll（上滑预取）+ Pull-to-Refresh（下拉刷新） |
| 页面 >2 屏高 | Back-to-Top 按钮（500px 出现阈值） |
| 全屏任务（浏览全量） | Push 新页（go_router） |
| 上下文内的确认/解释 | Modal Dialog |
| 瞬时通知（不打断） | SnackBar |
| 图片查看 | 全屏查看器 + Pinch-to-Zoom |
| 头部轮播 | Carousel（自动播放 + 无限副本） |

| 搜索框 | Search Field | 输入框 + 实时过滤列表 | 全部 |
| 开关 | Switch | 布尔设置项（设置页） | 设置 |

## 现用登记（2026-11-19 审计）

| 模式 | 使用处 | 选择理由 |
| --- | --- | --- |
| 横向年份 Chip 条 | 经典榜单页年份轴（全部 + 各年，固定列表上方） | 年份高频切换，需常驻且一键可达；19 个年份横向滚动，近期年份靠左；与指标同级，不放进筛选面板（用户 2026-11-25） |
| 年月切换条 + BottomSheet | 官方月榜详情（‹ 2026-11 ›，点月份开年/月网格） | 替代 Dropdown；用户 2026-11-21 反馈下拉切换 bug 多、有旧 Web 表单感；历史月份从 2013-03 起（对话榜 2017-07 起）需要快速跳转 |
| Drawer | 比赛榜页切赛道（contest 归一化赛道组 + 本地搜索 + 标题反馈） | 组数超 chip 行舒适区要搜 |
| FilterChip 行 | 题材榜页切题材（全部 + 各题材 + 本数） | 十来个短词，标签行最紧凑 |
| Segmented Control（SegmentedButton） | 经典榜单页切指标（点击/收藏/点赞/字数，4 个互斥，`showSelectedIcon:false` 无激活 ✔ + 尾部逆序按钮） | 2–4 互斥是分段按钮标准场景（选型速查表）；Tab Strip 已用于页内榜单切换同场景（官方榜单长篇页），不重复选（用户 2026-11-21） |
| 筛选面板（BottomSheet + Chip） | 经典榜单页四维筛选（状态/价格/题材/标签，标签多选 OR） | 统一入口 = AppBar `filter_list` + 激活条件计数角标（每个选中标签计 1，年份不计入）；live-apply 面板保持打开可连选、清除全部一键复位且不清年份；值列表 `/facets`，chip 不显示计数、选中不显示 ✔（`showCheckmark:false`，组件默认 true，用户 2026-11-21）；年份 2026-11-25 移出为顶部横向条 |
| 入口网格（3 列卡片 + 标题/描述） | 对话 tab 九入口（经典榜单/短/中/长/年份/比赛/题材/优质/随机） | 对话池字数跨度 3 万–177 万，单一收藏榜会被长篇占满（用户 2026-11-20）；先按篇幅分流，再给榜单轴 |
| 入口列表（List Tile + chevron） | 短篇 tab 六格入口（经典榜单/年份/比赛/题材/优质/随机） | 每行可带描述，比单行宫格信息密度高、撑满页面 |
| 入口网格（2 列卡片 + 标题/描述） | 中篇 tab 六入口（经典榜单/年份/比赛/题材/优质/随机） | 原单行题材 chips + 页内单列表信息量低（用户 2026-11-19 反馈）；六个榜单入口一屏可达，轴切换留在榜单页；总榜=经典榜单内收藏段（用户 2026-11-21） |
| 入口宫格（Grid） | 长篇首页四格行（分类/状态/比赛/经典榜单） | 短标签四格，宫格最省空间；第四格经典榜单与短篇/中篇/对话 tab 首位同构，原短篇入口让位（用户 2026-11-21） |
| 宽卡入口 | 首页宽卡（官方榜单置顶长篇 tab、对话 tab；萌神收录 / 授权作品） | 竖向堆叠大入口，视觉锚点；长篇页内 Tab 切换榜单，对话直达 m4，均无中间页 |

| 指标行（MetricBadge） | 列表行/详情页（字数→点击→收藏→赞） | 对齐官方 app 排版 |
| IP 徽标（Badge） | BookRowTile 标题行 | contest → IP 标签 |

## 多样性待办（后续新页面候选）

- **Segmented Control**：已用——日历 tab 粒度切换（月/周/日）。详情页「展示 / 量化」双模式切换（Phase 量化模式上线时）可复用。
- **Hero Animation**：大图精选 → 查看器目前直接 push，可加转场。
- **SnackBar**：观测刷新成功/失败目前是文字提示，可升级。
- **Skeleton Screen**：列表加载目前是 spinner，重列表可上骨架屏。
- **FAB**：若加「关注此书」全局动作，候选。
- **Breadcrumbs / Picker / Table / Slider**：暂无场景，先备查。
