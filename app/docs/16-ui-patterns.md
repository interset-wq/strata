# 16 · UI 模式登记（UI Pattern Registry）

> 目的：① **UI 多样性**——同类交互在不同页面尽量不重复用同一控件，避免整 App 模板感；
> ② **术语学习**——新增页面时先查本文找模式名字，再登记使用处。
> 分工：docs/15 管「语义 → icon」（同一语义任何页面同一个 icon）；本文管「场景 → UI 模式」。
> 本文与 docs/08（引擎 API）、docs/12（双模式契约）同级，是 UI 层的约束文档。

## 规则

1. **多样性规则**：两个页面做「同一类交互」（切轴 / 筛选 / 选择 / 列表分页）时，
   尽量选用**不同的**模式；同一页面内的同类交互保持自身一致。
2. **登记规则**：页面上首次使用某模式前，先在「现用登记」加一行（模式 + 页面 + 选择理由）。
3. **选型规则**：先查「选型速查表」按选择规模 / 任务类型定候选；两个候选都合适时，
   选当前 App 还没用过的那个。

## 选型速查表

| 场景 | 候选模式（按优先） |
| --- | --- |
| 2–4 个互斥选项 | Segmented Control（分段按钮） |
| 5–15 个短词选项（可换行） | FilterChip 标签行 |
| 15–50 个选项、需要搜索 | Drawer（侧滑面板） |
| 15–50 个选项、是"当前动作的参数" | Modal Bottom Sheet（底部抽屉） |
| >50 个选项 | 独立搜索列表页 |
| 列表 >一屏 | Infinite Scroll（上滑预取）+ Pull-to-Refresh（下拉刷新） |
| 页面 >2 屏高 | Back-to-Top 按钮（500px 出现阈值） |
| 全屏任务（浏览全量） | Push 新页（go_router） |
| 上下文内的确认/解释 | Modal Dialog |
| 瞬时通知（不打断） | SnackBar |
| 图片查看 | 全屏查看器 + Pinch-to-Zoom |
| 头部轮播 | Carousel（自动播放 + 无限副本） |

| 轻提示 | Toast / SnackBar | 底部浮出短暂消息，不打断操作（当前未用，预留） | 全部 |

| 图片查看器 | Image Viewer | 全屏看大图 + 捏合缩放（Pinch-to-Zoom） | 微信图片 |
| 搜索框 | Search Field | 输入框 + 实时过滤列表 | 全部 |
| 开关 | Switch | 布尔设置项（设置页） | 设置 |
| 操作暗示 | Affordance | "让用户知道这能点"的设计手段（箭头 ›、按钮、涟漪） | 设计概念 |
| 墨水涟漪 | Ink Ripple | Material 点击水波纹反馈 | Material 体系 |
| 视觉层级 | Visual Hierarchy | 用大小/粗细/颜色区分信息主次 | 设计概念 |

## 多样性待办（后续新页面候选）

- **Segmented Control**：已用——日历 tab 粒度切换（月/周/日）。详情页「展示 / 量化」双模式切换（Phase 量化模式上线时）可复用。
- **Hero Animation**：大图精选 → 查看器目前直接 push，可加转场。
- **SnackBar**：观测刷新成功/失败目前是文字提示，可升级。
- **Skeleton Screen**：列表加载目前是 spinner，重列表可上骨架屏。
- **FAB**：若加「加入书架」全局动作，候选。
- **Breadcrumbs / Picker / Table / Slider**：暂无场景，先备查。
