# 17 · 作者维度深挖（作者页改版：概览 + 代表作 + 时间轴）

> 产品设计文档（2026-11-22 定案）。范围 = 作者页（`author_page.dart`）改版 +
> 一处引擎小改（`author-books` 加一列）。**不新增抓取、不新增端点、不写用户
> 数据**——纯本地 seed 数据的展示层改版。

## 1. 意图与场景

用户 2026-11-22 选定三个场景（布局与其余取舍由 builder 自主定案）：

1. **作品时间轴**：作者什么时候入圈、各年产出、形式迁移——职业轨迹。
2. **质量画像**：代表作（各 form favs Top-1，E.30）、形式分布——值不值得追。
3. **统计面板**：在库/库外数量、出道年、年代跨度等聚合卡片——概览。

**非目标（v1 不做）**：追新（「作者有没有更新/新书」）——需要观测数据 +
订阅抓取，用户明确不选；协同/跨作者比较；库外书的质量数据（不在 seed，
没有 form/分位，不伪造）。

## 2. 现状与缺口

作者页现状（`app/ui/lib/pages/author_page.dart`）：

- 头部：按需资料（`/author-profile`，user.db 7 天缓存，docs/author-profile-
  on-demand）——头像/名/简介，失败降级不阻塞。
- 书目：`/strata/author-books` 分页（20/页，无限滚动，最新/最早切换），
  **已有年份分组头**（est_date DESC，0001 回填书沉底）。
- 行卡：封面 + 标题 + `est_date · status`——**无 form、无分位展示**。
- 库外作品区块（docs/author-profile-on-demand §6，2026-11-22 落地）。

缺口：

| 模块 | 缺口 |
| --- | --- |
| 时间轴 | 年份是裸数字，无职业上下文（出道/跨度）；年份未知书无分组头 |
| 质量画像 | `AuthorBooks` 的 SELECT **未取 `fav_pctl`**（行内恒 0）→ 同世代分位完全不可用；无代表作、无分布（E.30 结案：分位列退役，质量画像 = 各 form favs Top-1 + 形式分布） |
| 统计面板 | 分页加载，无全量视角，无聚合卡片 |

## 3. 数据契约（唯一引擎改动）

`GET /strata/author-books` 行不携带分位字段（E.30 结案：universe 分位列随种子
v9 退役——只能构建期现算、端上不可重算、无 user.db 镜像）。代表作 = 端上现算
**各 form favs Top-1**；统计（出道年/跨度）由 `est_year` 端上现算。

- 原 §3（行增 `fav_pctl`）在 v7 已实施、E.30 退役：`RankItem.FavPctl` 删除。
- 授权书（`is_licensed=1`）的 `pr` 在 seed 中恒 NULL（E.25 事实）→
  参与时间轴/统计，**不参与**代表作（favs 空值）。
- 其余全部端上现算（docs/07 模式：引擎给数据，端上算展示）：统计、代表作、
  分组全由 `author-books` 全量行在 UI 计算。

## 4. 页面结构（自上而下）

1. **头部**（现有，不动）：头像/名/简介 + dead 提示。
2. **作者概览卡**（新）：
   - 四个 mini 统计：`在库 N` / `库外 M`（offlibrary 长度）/ `出道 YYYY（估）`
     （在库非 0 est_year 的最小值）/ `跨度 X 年`（最大-最小；单年显示 `—`）。
   - 形式分布：横排 chips（`长篇 N · 短篇 N · 对话 N …`），只显示非零 form，
     中文形式名（复用现有 form 展示口径）。
   - 分位分布：四段 mini 条 + 计数（`≥99%` / `95–99%` / `90–95%` / `<90%`
     收藏分位），`fav_pctl=0`（含授权书）归「无数据」计数，不画段。
   - 在库 0 本时整卡隐藏（库外区块照常）。
3. **代表作**（新）：每个出现过的 form 取 `fav_pctl` 最高一本（同世代分位，
   **禁止用原始收藏数排序**——量化红线 docs/12）；横向封面行（封面 + 标题 +
   form + `前 x%`，x = (1 - fav_pctl)×100 取整，100 以下）。该 form 下全为
   无分位书时不出卡。在库 0 本时整区块隐藏。
4. **作品时间轴**（现有年份分组列表 + 两处增强）：
   - 保留：年份分组头、组内 est_date DESC、最新/最早切换、行卡、back-to-top。
   - 新增：无年份书（est_date NULL/'' 或 0001 哨兵或 est_year=0，统一
     判定）组「年份未知」分组头（同点+分隔线样式）。20260503.26 种子
     实测 **0 本**此类书（无 NULL/'' est_date、无 est_year=0）——分组为
     防御性实现，非空才渲染，不造假验收数据；est_year=2006 的 3 本
     （SFACG 元年 2007 前一年）正常归「2006」组，出道年可能显示 2006
     （估）——数据说了算，不特判。
   - 新增：时间轴区块顶部一行注：`年份为估算（锚点插值）；未知年份置末`。
5. **其他作品（库外）**（现有，不动）。

### 4.5 加载方式（builder 定案）

**单次拉全量**：`authorBooks(limit: 200, offset: 0)` 一次取回（200 = 统一
limit 契约上限，docs/08，不改全局 cap；本地 SQL，成本可忽略）。
20260503.26 种子实测（2026-11-22）：单作者在库最多 36 本（天闻角川），
一页必够；防御性尾部注「在库 >200，仅显示前 200」，实际不会触发。
移除分页 20/页、无限滚动、`_booksDone` 状态机——概览/
代表作需要全量，单次取回后即时计算，无「部分数据」中间态。`ListView.builder`
渲染仍是惰性的，内存无压力。

### 4.6 切换排序

保留 AppBar 最新/最早切换（= 年份分组方向反转），实现为端上对已取回的
全量列表重排（不再触发网络）。

## 5. 红线（承 docs/12 + docs/07）

- 质量排序唯一依据 = 同世代收藏分位 `fav_pctl`：代表作、分位分布都用它；
  原始累计收藏数只可展示、不可作排序/筛选依据。
- `est_year`/`est_date` 是估算值（锚点插值）：时间轴注释必带；未知年份
  置末成组，不编造、不外推。
- 库外书无 form/分位/字数（不在 seed）：维持标题 + nid 行，不进任何质量
  模块。
- 授权书进时间轴与数量统计（展示层，现有行卡带授权徽标行为不变），不进
  代表作与分位分布（分位恒 NULL）。
- 不新增抓取、不新增端点、不写 user.db；作者页不触发任何官方请求之外的
  网络行为（`/author-profile` 的既有按需抓取不变）。

## 6. 验证

- Go：`author-books` 返回 `fav_pctl`（api 层测试断言种子书非 0、授权书 0）；
  `go build/vet/test` 全绿；**NDK 重编译**（Go 有改动）+ jniLibs 同步。
- Dart：`flutter analyze` 零问题 + `flutter test`；debug APK 装机。
- 真机验收口径：① 概览卡数字与列表计数一致（在库/库外/出道/跨度）；
  ② 代表作 = 各 form 收藏分位最高（与详情页分位徽标一致）；
  ③ 有 2006 年书的作者（种子 3 本）归「2006」组头、出道可显示 2006（估）；
  年份未知组无书时不渲染（防御性）；④ 切换排序 = 年份方向反转；
  ⑤ 库外区块行为不变；⑥ 无在库作品的作者：概览卡与代表作隐藏，
  库外区块照常。
- 文档同步：`08-engine-api.md` author-books 行补 `fav_pctl`；
  `docs/author-profile-on-demand.md` §1 书目节补本文档指针；
  `author_page.dart` 顶部 doc comment（现为「时间轴 UI 待改版」）更新为
  已改版指向本文档。
