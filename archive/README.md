## 三句话版本（产品定位，早期稿的保留部分）

1. **官方 11 个榜回答「现在什么火」，我们回答「过去什么好」。**
   种草榜 15 分钟刷新、月票按月清零、完结榜也只是当期口径——没有任何一个榜用累计成绩。
   一本 2015 年完结的神作不会给站方带来收入，所以永远进不去；而它的成绩实测不随时间衰减。
2. **差异化靠时间观不同，不靠「官方漏了哪个维度」。**
   官方是「现在有多火」，累计成绩是「历史上有多好」。角色榜是唯一需要正面承认的对手维度：
   它印证角色是找书方式之一，但只能给「现在最热的角色」。
3. **端上抓详情 = 分布式爬虫，限速与缓存是生存问题。**
   详情缓存 TTL 14 天、每设备限速；服务端是第三期的事，
   四条进入条件全部满足才动手（见 [`architecture.md`](./architecture.md) §6.5 末）。
