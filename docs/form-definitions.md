> **状态**：已实施，`seed_version=20260503.19` 落地（含 E.9–E.21 全部条款）。
> 本文是 `books.form` 六值判定与收录资格的**唯一权威口径**；实现真源：
> 分类 `analysis/lib/forms.py::classify`（对话判据 `analysis/lib/dialogue_form.py`），
> 收录资格 `app/tools/seedbuild/seed_policy.py`。本文不改代码、不改定年、不硬编码分布数字。
> 上游依据：09 附录 D、报告 22（对话识别）、报告 06 §4（征文命名）、契约 12 §6。

## 1. 字段契约

```
books.form TEXT NOT NULL CHECK (form IN
  ('invalid','short','medium','long','dialogue','ip_collab'))
CREATE INDEX idx_books_form ON books(form, favs DESC);   -- schema v2→v3，24→28 列
```

- `form` 是**互斥单值标签**，只作榜单过滤，不参与任何分位计算；
  分位五列（`fav_pctl` 等，分母=完整 universe）与 D2 `deep_ranks` 不动。
- `validate.py` 断言取值域并统计分布，记入 `manifest.json`；
  引擎榜单/发现流端点接受 `form` 过滤参数（契约 12 §6），UI 须标注「形式为推断，非官方分类」。

## 2. 判定优先级

从字数兜底开始，高优先级判据依次覆写（互斥单值靠逐级覆盖实现）：

| 级 | 判据 | 性质 | 覆写值 |
|---|---|---|---|
| 0（兜底） | 字数切档（含 invalid 下界） | 估计 | `invalid/short/medium/long` |
| 0.5 | 正文征文否决对话形态（§3.5 / E.21） | 确定性 | 保持字数档（仅中篇档） |
| 1 | 对话形态判据 v2（§3.5） | 估计（章节真值校准） | `dialogue` |
| 1.5 | 短篇点击天花板（§3.1 / E.19） | 确定性（App 目验） | `invalid` |
| 2 | 对话征文标记（§3.5） | 确定性 | `dialogue` |
| 3（最高） | IP 合作封闭名单（§3.6） | 确定性 | `ip_collab` |

- **对话高于篇幅**：对话每章约 500 字、整本可长（锚点 88 万字），先按字数切会把长对话
  排进长篇榜——这正是 form 要消除的噪声。
- **IP 置顶**：名单封闭、确定性最高，与对话/短篇实测零交。
- **级 1.5 只作用于仍为 short 的书**：判据是 `words ≤ 5 万 且 clicks > 215,723`，
  即「越过真短篇点击上限却还在短篇档」——僵尸或假短篇，数据不可信，归 invalid。
  级 1 已判 dialogue 的越线书不受影响（当代越线大多是对话）。
- **正文征文否决形态估计（E.21，用户定）**：征文按组别投稿，对话组/点鸭/分支对话
  都带显式关键词（级 2 已覆盖），其余征文标记（「X征长篇/中篇/短篇」「冬季征文」
  「玄幻征文」…）一律是**正文**。故中篇档（5–15 万字）内，有征文标记而无对话关键词
  的书不参与级 1，形态由字数决定。级 1 是估计、征文标记是确定性证据，估计不得推翻
  确定性。只护中篇档：短篇档的同人征文仍按 E.17 判对话（该档的对话份额太高）。
- **级 1 不得救回 invalid**（E.13）：僵尸书章节数极少、ckw 天文高（4166：775 字
  ckw=13.2），形态估计会误翻僵尸（实测 2,405 本）；只有级 2/3 确定性证据可以救回。
- **征文名不定篇幅**（E.12，红线）：`contest` 含「短篇/中篇/长篇」一律不覆盖字数——
  征文名只反映投稿赛道（86279「少女与龙」挂五征短篇却 13.9 万字、641618 挂十一征
  中篇却 129 万字）。对话征文与 IP 名单是确定性身份，照常覆盖。

## 3. 六值定义

字数边界：`invalid < 2,000 ≤ short ≤ 50,000 < medium ≤ 150,000 < long`。
短/中切点 5 万为用户口径（官方旧口径 3 万、2026 新口径 15 万单切点均不采用）。

### 3.1 `invalid`（僵尸 / 假短篇）

两类，均无收录资格：

1. `words < 2,000` 且未被级 2/3 救回。2000 = app 正常章节字数下限，正常书至少一章；
   <2000 几乎都是目录抓取残缺的僵尸（锚点 4166：775 字已完结）。
2. `words ≤ 50,000` 且 `clicks > 215,723`（E.19，用户 App 目验）。越线者不是真短篇：
   内容被替换成无意义文本的僵尸（When It Sucks，34,297 字、162 万点击，阅读按钮仍在）
   或作者恶意标注完结的长篇（字数只统计到前段）。字数、状态、点击三者都不可信，
   故不判 long——没有可靠字数可判它是长篇。级 1 的对话命中优先（当代越线书多为
   对话，v2-d 已判 dialogue）。

universe 24,021 本。`form` 标签不随 status 变；收录层剔除、无任何豁免（P6 守门，入种恒 0）。

### 3.2 `short`（短篇）

`2,000 ≤ words ≤ 50,000`。1 万–5 万未成形作品归 short，不设 tiny 档。
universe 131,177 本。短篇只是形式不是质量：≤5 万池中「已完结 + favs<5 + 字数<8千」
的伪完结劣质书占已完结短篇 33.7%；优质判定见 §6。

### 3.3 `medium`（中篇）

`50,000 < words ≤ 150,000`。universe 26,155 本。
官方 2026 已取消中篇档，但榜单过滤必须保留——并入短篇会让 favs Top200 里 197 本是
中篇、真短篇永无推荐位（09 附录 D §D.1）。

### 3.4 `long`（长篇）

`words > 150,000`。universe 17,280 本。长篇榜须排除 `dialogue`（form 核心收益）。

### 3.5 `dialogue`（对话/互动）

universe 42,296 本。互动小说并入本值（本地无法单独识别，不硬猜第三值）。

**级 2 征文标记（确定性）**：`contest` 含「对话」或「点鸭」＋用户 App 目验核实的 7 个
征文（`怪谈异闻主题征文长篇`、`春节征文长篇`、`穿越主题征文`、`星穹小说家征文`、
`春节征文短篇`、`战斗主题征文`、`怪谈异闻主题征文短篇`），合计确定集 12,286 本。

**级 1 形态判据 v2（估计；E.13 R18 + E.16 天花板 + E.17 同人条款 + E.18 时间下界与 IP 标题，用户裁定，章节真值校准）**，七条款取 OR，且**全部受时间下界约束**：

| 条款 | 条件 |
|---|---|
| ① | 同人（`genre=同人` 或 tags 含同人）且 `price_type ∉ {VIP,签约}` 且 `words ≤ 20,000` |
| ② | 同人且 `ckw ≥ 6`（无字数上限：115 万字同人长对话也判出） |
| ③ | 非同人且 `words ≤ 50,000` 且 `ckw ≥ 13` |
| ④ | 非同人且 `50,000 < words ≤ 150,000` 且 `ckw ≥ 30` |
| ⑤（E.16） | `words ≤ 50,000` 且 `clicks > 215,723`（**不限同人/签约**） |
| ⑥（E.17） | 同人且 `words ≤ 50,000`（不看 `ckw`、不看签约） |
| ⑦（E.18） | 标题含米哈游 IP 词且 `words ≤ 50,000` |

**时间下界（E.18，硬约束）**：全部形态条款只在 `nid ≥ 83,818`（2017-07）生效。
对话体是 2017-07 才上线的产品线，此前建档的书不可能是对话。证据链：历史月榜
`MonthlyBoy.ashx` 的 rank=4（对话月票榜）首月为 2017-07，2016-10 至 2017-06
全部为空；同月出现首批「五征对话小说」投稿，最小 nid 83,818 / 2017-07-03；
此前十年零对话征文标记。早期同人短篇按散文计，回退 1,709 本（其中 1,664 本是
2007–2017 的传统同人短篇，标题含 IP 词的仅 79 本，且「崩坏」在 2010 年作普通
词汇用，如「崩坏の迷宫」）。征文标记（级 2，确定性）不受下界约束。

**正文征文否决（E.21，2026-11-19 用户裁定）**：上述七条款在中篇档（5–15 万字）内
不适用于带非对话征文标记的书——`contest` 非空且不含「对话/点鸭」即为正文组投稿，
形态由字数决定。受影响 8 本（「伊卡洛斯在约战」五征长篇、「变身卡莲的小日常」
玄幻征文等，均连载中）由对话改判中篇；短篇档不受影响（同人征文仍判对话）。

`ckw` = 快照 `clicks ÷ words`：同字数下对话章节多、曝光与互动天然更高
（真短篇头部「听雨」3.8 vs 对话「黑符」71.6）。校准：n=193（真值 = App API 章节
中位字数 ≤1100），精确率 0.92、召回 0.85；`ckw < 3` 实测 0 对话。
条款⑤依据（E.16，2026-11-19）：用户 App 目验确认「回到旧时光」clicks 215,723 为
真短篇点击上限（真短篇章节少、曝光低；36 本误判短篇全部 >226k），专收 ckw 6–13
灰带的高曝光对话文，universe 净增 155 本对话。
条款⑥依据（E.17，2026-11-19）：种子 short 层 170 本同人经逐一目验全部误判——头部
十余本为崩坏/综漫/型月系，20 万点击、3–4 万字，ckw 5.2–6.3 恰好卡在②的阈值 6 之下
（②在种子内命中 0 本，事实上空转）。同人区是对话/互动产品线的主场（§7、报告 22），
故对同人改按「字数额度」判形态：同人而字数压不进长篇档（>5 万）者判对话；
同人长篇（>5 万）不适用，那是正常散文连载。
条款⑦依据（E.18，2026-11-19 用户裁定「有崩坏等米哈游特征的都是对话」）：标题含
米哈游系 IP 词是对话同人的强特征（报告 22 §4），但只覆盖头部、不算确定性，故仍
属级 1 估计；限 `words ≤ 5 万`——同字数的 medium/long 里 IP 书 `ckw` 中位仅
1.33 / 0.95（如「转生为温迪到崩坏世界重写版」10.7 万字 179 万点击），是正常
散文长篇，不能按标题翻。universe 内 1,745 本 short 由⑦翻为对话。
三条天花板（用户 App 目验，E.17 固化，P7 守门，E.19 升级为判定）：short 层点击
≤ 215,723（回到旧时光）、favs ≤ 5,478 与 praises ≤ 2,389（听雨）。三条线**全时期
有效**：早期书的点击虽累积十数年，但越过 215,723 的 23 本经 App 目验全部不是短篇
——内容被替换的僵尸（When It Sucks）或作者恶意标完结的长篇（E.19），已归 `invalid`。
故 P7 断言不再加时间下界，short 层现为零越线（最大值恰为三条线本身）。
残差：章均 1100–1250 字边界书两可；非同人 >15 万字无判据，接受该召回缺口。
**字数不判形态**：形态条款的字数上限只用于群体估计，禁止用它否定已被确定性证据
认出的长对话；且级 1 不得救回 invalid（§2）。

### 3.6 `ip_collab`（IP 合作）

universe 935 本。判定 = `contest` 精确命中六类封闭名单：
楚楚动仁（咪咕×SFACG）、崩坏3、少女前线、龙之谷、失业魔王、英雄再临。
名单封闭（集中 2016–2019），无需启发式。标题 IP 词（芙宁娜/钟离等）是同人对话特征、
不是 IP 合作；「超新星杯」是短篇赛事，按字数归 `short`。

## 4. 种子收录资格

`classify` 产出纯标签、不随 status 变；收录资格在种子层判定：

```python
def seed_admit(row, form) -> bool:
    if form == "invalid":
        return False                                  # 僵尸，无豁免（P6）
    if form == "medium" and row.status != "已完结":
        return False                                  # 中篇必须已完结（E.20，无豁免）
    if form == "short" and row.status != "已完结" and row.fav_pctl < 0.98:
        return False                                  # 连载短篇 = 弃书（E.11）
    return True
```

- **弃书规则（E.11）**：短/中篇阅读本质是「一口气读完」，连载中视为作者弃书，
  丧失收录资格（`status` 字段不可靠，见下条豁免的存在理由）。
- **中篇无豁免（E.20，用户定）**：`medium` 且连载中的书一律出局，不看 `fav_pctl`。
  5–15 万字仍在连载的中篇，绝大多数是作者弃掉的长篇（字数还会涨、结构是长篇），
  开口子等于放大量太监长篇进种子。征文保底也不例外，P8 守门。
- **质量豁免（E.13，仅 short）**：同代 `fav_pctl ≥ 0.98` 的连载**短篇**不算弃书——
  作者可能只是忘点完结（锚点 24132）。豁免**不等于直接入库**：仍须经质量锚
  （Top20k/月榜/banner/短篇双分位/深榜）入种，实际豁免 31 本。
- **征文保底豁免（E.9）**：每征文 ≥3 本保底从全池选书、不查 status（部分比赛完结率
  极低）；保底候选 `words ≥ 1万`，天然不碰 invalid，故 invalid 无豁免。E.20 起
  保底也不得选连载中篇。种子内连载短篇只能来自保底路径（P5 守门）。
- **短篇双分位渠道噪声底（E.15）**：Top-2000 候选须 `favs ≥ 5`（与征文保底同门槛；
  分位仍在全池上算，先过滤会缩小组内分母、整体扭曲排名）。翻年改组曾让
  38821（favs=3 的 3-6k×2014 小组头部）无锚入种，违反 P2。

**八条后置断言**（`seed_policy.postconditions()`，重建时强制）：
P1 合格深榜书全入池；P2 favs<5 且 <1 万字须有外部锚；P3 收藏覆盖回退 ≤0.2pp
（合格书口径，分母剔除弃书+invalid）；P4 每征文 ≥3 本；P5 弃书仅经保底入种；
P6 invalid 零入种；P7 种子内 short 不越三条天花板（全时期）；P8 连载中篇零入种。
`20260503.19`：P1–P8 全 PASS。

## 6. 优质短篇判定（与 `form` 正交，推荐层用）

`form` 只回答「是不是短篇」，不回答「是不是好短篇」。判定规则：

- **优质 = 同代高口碑分位**：用 `fav_pctl`（`est_year` 世代内、完整 universe 分母），
  **严禁绝对 favs 门槛**——短篇头部 favs 跨世代差 13 倍（P99 从 2012 年 79 →
  2020 年 1,081），绝对门槛系统性偏向后期、埋没早期优质短篇。
- `pr`/`pctl_pr` 作辅助；绝对 favs 只作详情页展示锚点，禁止回流推荐打分（契约 12 §3.2）。
- 候选池可靠性下限 `favs ≥ 10`（PR 可算，报告 21）；伪完结劣质书（已完结 + favs<5 +
  字数<8千一类）不进优质候选池，是否整行剔除另案评估。
- **长篇区排序信号是 `lqs`**（篇幅加权口碑分，
  见 [`length-weighted-quality.md`](./length-weighted-quality.md)），与优质短篇判定
  均接入契约 12 §3.2 白名单。

依据（本地现算）：① 字数分不开优质与劣质（favs<5 档字数 P25/P75 = 2,380/9,398，
favs≥2000 档 = 18,904/26,887，有重叠）；② 劣质书拉扁中位数（≤3 万短篇 favs 中位数
个位数，伪完结劣质 10,297 本收藏总和仅 14,205）；③ 短篇在走下坡路，必须世代归一
才能让各代头部进入候选。

## 7. 已定边界事项

- **2000–1 万字归 short**（用户定），<2000 归 `invalid`；不设 tiny 档。
- **互动不单列**，并入 `dialogue`。
- **对话 vs 篇幅交叠**（对话征文∩短篇命名 484 本、形态∩短篇命名 375 本）一律按
  优先级归 `dialogue`，无需抽样复核（抽样只影响数百本归类，不改优先级方向）。
- **IP 名单封闭**，无待抽样项。
- **form 是估计值**：多数书靠字数兜底（篇幅征文名覆盖已取消），产物与 UI 须标注
  「形式为推断」。
