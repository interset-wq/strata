## 0. 一句话结论

给 `books` 主表加**一个互斥单值列** `form`，取值 `invalid / short / medium / long /
dialogue / ip_collab`，按「**IP 合作 ＞ 对话征文 ＞ 对话形态 ＞ 字数兜底**」
的优先级判定（IP 合作因名单封闭置顶）。目的是让榜单按形式过滤、消除噪声
（长篇榜排对话、短篇榜不被中篇挤压），`form` 只作分类标签、不参与任何分位计算。
三条收录资格约束（用户 2026-11-19 定，均在种子收录层生效、`form` 标签本身不变）：
1. **短/中篇只取已完结**——阅读本质是「一口气读完」，连载中视为作者弃书（E.11，§3.1/§3.2）；
   例外：同代 `fav_pctl ≥ 0.98` 质量豁免（E.13，status 字段不可靠）+ 征文保底豁免（E.9）；
2. **`invalid` 僵尸书无资格**——`words<2000`（app 正常章节下限×至少一章）多为目录
   抓取残缺，种子层剔除（E.12，§3.0）；
3. **篇幅纯按字数**——取消「征文名定篇幅」：征文名只反映投稿赛道、不反映真实字数
   （`少女与龙` 挂「五征短篇」却 13.9 万字），E.12 一并取消（§2/§3.3）。

**三条红线（用户 2026-11-18 定，E.12 补第 3 条）**：
1. **短篇边界 = 5 万字**（原 3 万，用户调宽）；中篇 5–15 万、长篇 >15 万。
   下界 `invalid < 2000 ≤ short`（2000 = app 正常章节下限，正常书至少一章）。
2. **形式归形式、质量归质量**：`form` 只回答"是不是短篇"，**不回答"是不是好短篇"**。
   优质短篇的判定必须用**同代分位 `fav_pctl`**，**严禁**用绝对 favs 设门槛——
   短篇头部 favs 跨世代差 13 倍（§6.1），绝对门槛会系统性偏向早期、埋没后期优质短篇。
3. **征文名不定篇幅**（E.12）：`contest` 含「短篇/中篇/长篇」**不再覆盖字数切档**——
   征文名只反映投稿赛道，真实字数由 `words` 决定（锚点 86279 `少女与龙` 挂五征短篇
   却 13.9 万字、641618 挂十一征中篇却 129 万字）。对话征文与 IP 名单仍是确定性身份、
   照常覆盖（§2）。

## 2. 判定优先级（核心，必须按此顺序覆盖）

互斥单值靠**逐级覆盖**实现：从兜底值开始，高优先级判据依次覆写低优先级结果。
后判据命中即覆盖前判据。优先级从低到高：

| 级 | 判据 | 性质 | 覆盖后的值 |
|---|---|---|---|
| 0（兜底） | 字数切档（含 invalid 下界） | 估计 | `invalid` / `short` / `medium` / `long` |
| 1 | 对话**形态**判据 v2（同人簇 / clicks÷字 复合指标） | 估计（章节真值校准） | `dialogue` |
| 2 | 对话**征文**标记 | 确定性（用户核实） | `dialogue` |
| 3（最高） | IP 合作征文名单 | 确定性（封闭名单） | `ip_collab` |

> **E.12 删除原「级 1 篇幅征文命名」**：原表该级用 `contest` 含「长篇/中篇/短篇」
> 覆盖字数，实测并不可靠——征文名是投稿赛道，作者常写超字数（86279 挂短篇却 13.9 万、
> 641618 挂中篇却 129 万）。现在篇幅**纯按字数**，征文名不再参与篇幅判定。

**为什么对话高于篇幅**：对话小说「每章约 500 字、整本可长」（锚点 570712 达 88 万字），
若先按字数切档，长篇对话会落进 `long`、污染长篇榜——这正是加 form 要消除的噪声。
故对话（级 1/2）必须覆盖字数（级 0）。同理，被**确定性证据**认出的短对话即便
`words<2000` 也归 `dialogue`、**不落 invalid**（字数不判形态，§3.4）；但**级 1 形态
估计不得救回 invalid**（E.13）——僵尸书章节数极少、clicks/字 天文高（4166 775 字
ckw=13.2、181214 23 章×11 字 ckw=291），ckw 判据会把僵尸误判成对话。

**为什么 IP 置顶**：名单封闭、确定性最高，且与对话/短篇实测零交
（IP∩对话=0、IP∩短篇=0，见 §3.5），放哪级都不冲突，置顶便于心智。

## 3. 六值定义（逐个精确）

### 3.0 `invalid`（无效/僵尸，E.12 新增）

- **判据**：`words < 2,000` 且未被对话/ IP 判据救回。2000 = app 正常章节最少字数，
  正常书至少一章 → 正常书 `words ≥ 2000`；<2000 几乎都是目录抓取残缺的僵尸书
  （锚点 4166「辞别黄昏的小镇」words=775、favs=43、已完结，据此入选旧种子）。
- **性质**：`form` 仍是纯标签、不随 status 变；`invalid` **无收录资格**，种子收录层
  从质量锚剔除（P6 守门入种恒为 0）。征文保底候选 `words ≥ 1万`、天然不碰 invalid。
- **优先级低于确定性证据、高于形态估计**：words<2000 的书若被**确定性证据**
  （级 2 对话征文 / 级 3 IP 名单）认出，归 `dialogue`/`ip_collab`，不算 invalid；
  但级 1 形态估计**不得**救回 invalid（E.13——僵尸书 clicks/字 天文高，ckw 判据
  会误救，实测 2,405 本僵尸被误翻）。全库 invalid 23,995 本，种子内 0 本。

### 3.1 `short`（短篇）

- **字数**：`2,000 ≤ words ≤ 50,000`（下界 2000 见 §3.0；上界**用户 2026-11-18
  由 3 万调宽到 5 万**）。1 万–5 万未成形作品仍归 short，不设 tiny 档。
- ~~**征文命名覆盖**~~（E.12 取消）：`contest` 含「短篇」**不再**覆盖字数——见 §0 红线 3。
- **完结条款（用户 2026-11-19 定）**：短篇收录池要求 `status = 已完结`。
  短篇的阅读本质是「一口气读完」；连载中且 ≤5 万字的书「不是一口气读完」，
  视为**作者弃书**——它已丧失收录资格（比已完结劣质书更没有资格）。
  `classify_form` 不随 status 变化（篇幅标签仍为 `short`，供分析层参考）；
  **种子收录层负责剔除**（§4 `seed_admit`）。
  **征文保底豁免**：E.9 的每个征文 ≥3 本保底从**全池**选书、不检查 status——
  部分比赛（如九征短篇）完结率极低，套用弃书规则会使 P4 无法达成；
  豁免仅发生在保底路径，最终种子内连载短/中篇只能来自征文保底（§4 P5）。
  **E.13 质量豁免**：同代 `fav_pctl ≥ 0.98` 的连载短/中篇不算弃书——status 字段
  不可靠（24132「回到旧时光」同代前 0.85% 的顶尖短篇，作者只是忘了点完结；
  且快照口径「连载中」在当期数据里已是「断更」）。豁免书仍须有质量锚才能入种，
  实际豁免 140 本。
- universe 内字数兜底+命名命中合计 **130,841 本**（§5 分布，优先级互斥后）。
- **短篇只是形式，不是质量**：≤5 万的书里大量是 favs<5、字数<8 千的"伪完结"劣质书
  （占已完结短篇 33.7%）；优质短篇的判定见 §6.1，**不在 form 字段里做**。

### 3.2 `medium`（中篇）

- **字数**：`50,000 < words ≤ 150,000`（随短篇边界由 3 万改为 5 万）。
- ~~**征文命名覆盖**~~（E.12 取消）：`contest` 含「中篇」**不再**覆盖字数——
  641618 挂「十一征中篇」却 129 万字，现按字数归 `long`。
- **保留中篇档**：官方为投稿评审在 2026 取消中篇，但**榜单过滤必须保留**——
  中篇并入短篇会让 favs Top200 里 **197 本是中篇、仅 3 本真短篇**，真短篇永无推荐位（09 附录 D §D.1）。
- **完结条款（用户 2026-11-19 定）**：与 §3.1 同——中篇收录池要求
  `status = 已完结`；连载中且 5–15 万字的书视为作者弃书、不进种子（§4 `seed_admit`）。
  同样受征文保底豁免约束（§3.1）。

### 3.3 `long`（长篇）

- **字数**：`words > 150,000`（长篇边界不动，仍是 15 万）。
- ~~**征文命名覆盖**~~（E.12 取消）：`contest` 含「长篇」/「X 征」**不再**覆盖字数——
  征文名只是赛道，种子内有 1,345 本挂「长篇征文」却 ≤15 万字，现按字数归 short/medium。
- **长篇榜须排除 `dialogue`**：这是 form 的核心收益之一。

> **字数切点**：短/中切点用**用户 2026-11-18 定的 5 万**（非官方 3 万，也非官方 2026
> 的 15 万单切点）；中/长切点保留 2023 口径的 15 万。数据集主体是旧口径年份，
> 官方 2026 把中篇并入短篇（1–15 万一刀切）会毁短篇榜，不采用。
> 篇幅命名仅覆盖约 16.9%，**多数靠字数兜底**——这是本字段软肋，产物须标注「形式为估计值」。

### 3.4 `dialogue`（对话/互动）

分两档，均覆盖篇幅判定：

- **级 3 征文标记（确定性）**：`contest` 含「对话」或「点鸭」= **10,304 本**（mA）；
  加用户 App 目验判 T 的 7 个征文（ `怪谈异闻主题征文长篇`、`春节征文长篇`、
  `穿越主题征文`、`星穹小说家征文`、`春节征文短篇`、`战斗主题征文`、
  `怪谈异闻主题征文短篇`）= **1,982 本**（mT）。两者互斥，合计征文确定集 **12,286 本**
  （报告 22 口径，全库）。universe 内同为 12,286（无授权/越界书命中）。
- **级 1 形态判据 v2（估计；E.13，用户裁定 R18，章节真值校准）**：三层 OR——
  ① 同人特征（`genre=同人 或 tags 含同人`）**且** `clicks/字 ≥ 6`；
  ② 非同人 **且** `words ≤ 5 万` **且** `clicks/字 ≥ 13`；
  ③ 非同人 **且** `5–15 万字` **且** `clicks/字 ≥ 30`；
  另保留原条款：同人 **且** `price_type ∉ {VIP,签约}` **且** `words ≤ 20,000`。
  `ckw` = 快照 `clicks ÷ words`（同字数下对话章节多、页面曝光与互动天然更高；
  真短篇头部「听雨」3.8 vs 对话「黑符」71.6）。校准（`out/form_calibration.jsonl`，
  n=193，真值 = App API 章节中位字数 ≤1100）：**精确率 0.92、召回 0.85**；
  `ckw < 3` 的书 0 对话。残差：章均 1100–1250 字边界书两可；病毒式真散文
  （ckw ≥ 50）可能误判。**该判据不得救回 invalid**（僵尸 ckw 天文高，§3.0）。
  动机锚点：421290「成为符华圣痕的黑符」30,268 字、favs 7,881 >「听雨」5,478，
  章节实测 44 章 × 650 字 = 对话；原判据（≤2 万字）漏掉全部 2–5 万字对话。
- **互动小说并入 `dialogue`**：互动是对话子集、近年独立，本地**无法单独识别**
  （锚点 691941 的 `contest` 空、`genre=古风`），不硬猜第三值。
- **字数不判形态**：对话小说整本可长，形态判据的 ≤2 万字只用于群体估计，
  **禁止**用它否定一篇长对话小说的 `dialogue` 归属。

### 3.5 `ip_collab`（IP 合作）

- **判定 = 征文名称精确命中封闭名单**（用户 2026-11-18 定）：
  楚楚动仁（=咪咕×SFACG）、崩坏3、少女前线、龙之谷（游戏联动）、
  失业魔王、英雄再临（站内成功 IP 衍生）——**六类，universe 内 935 本**。
- **理由**：SFACG 近几年没有过 IP 合作征文，名单是封闭历史集合（集中 2016–2019），
  按 `contest` 名称命中即可，**无需抽样、无需启发式**。
- **标题 IP 词不是判据**：米哈游系 IP 词（芙宁娜/钟离/琪亚娜等）是对话小说同人特征
  （报告 22 §4），不是 IP 合作；IP 合作组同人 genre 占比 0%、标题 IP 词 26.1% 只是伴随现象。
- **「超新星杯」不是 IP 合作**：它是站内**短篇赛事**（464 本，`contest` 含「短篇」），
  按篇幅命名归入 `short`（报告 06 §4 已明确）。此前的口径误认已纠正。

## 4. 判定伪代码（可直接实现）

```python
def classify_form(row) -> str:
    w = row.words
    # 级 0 兜底：纯字数切档（E.12 取消篇幅征文命名覆盖；含 invalid 下界）
    form = ("invalid" if w < 2_000 else
            "short" if w <= 50_000 else
            "medium" if w <= 150_000 else "long")

    c = row.contest or ""
    # 级 1 对话形态判据 v2（估计，覆盖篇幅但**不得救回 invalid**——僵尸 ckw 天文高）
    tong = (row.genre == "同人") or ("同人" in (row.tags or ""))
    unsigned = row.price_type not in ("VIP", "签约")
    ckw = row.clicks / max(w, 1)          # 快照值；clicks 缺失时按 0 处理
    if (tong and unsigned and w <= 20_000) or (tong and ckw >= 6) \
            or (not tong and w <= 50_000 and ckw >= 13) \
            or (not tong and 50_000 < w <= 150_000 and ckw >= 30):
        if form != "invalid":
            form = "dialogue"

    # 级 2 对话征文标记（确定性，覆盖形态/篇幅/invalid）
    if ("对话" in c) or ("点鸭" in c) or (c in USER_VERIFIED_T):
        form = "dialogue"

    # 级 3 IP 合作（最高，封闭名单）
    if any(name in c for name in IP_COLLAB_NAMES):
        form = "ip_collab"

    return form
```

```python
def seed_admit(row, form) -> bool:
    """收录资格（用户 2026-11-19 定，E.11 + E.12 + E.13）：
    ① 短/中篇连载中且同代 fav_pctl < 0.98 = 弃书，无资格
       （§3.1/§3.2 完结条款；E.13：pctl ≥ 0.98 质量豁免——status 字段不可靠）；
    ② form=invalid（words<2000 僵尸书）无资格（§3.0），无任何豁免。
    `classify_form` 是纯标签、不随 status 变；本函数是种子收录层唯一落点。

    例外：征文保底（E.9）从全池选书、豁免弃书规则——部分比赛完结率极低
    （最终种子内连载短/中篇只能来自保底，P5 守住）。保底候选 words>=1万、
    天然不碰 invalid，故 invalid 无豁免（P6 守住入种恒为 0）。
    E.13 豁免不是直接入库：豁免书仍须有质量锚（Top20k/月榜/banner/短篇补/深榜）。
    """
    if form == "invalid":
        return False
    if form in ("short", "medium") and row.status != "已完结":
        if row.fav_pctl < 0.98:
            return False
    return True
```

**六条后置断言**（`seed_policy.postconditions`，quality-anchor 重建时强制）：
P1 合格深榜书全入池（深榜分母已排除 ineligible）；P2 favs<5 且 <1 万字须有外部锚；
P3 收藏覆盖回退 ≤0.2pp（**合格书口径**：分母剔除弃书+invalid）；P4 每个征文 ≥3 本；
P5 弃书仅经征文保底豁免入种（越界=0）；P6 invalid 零入种（越界=0）。

**注**：E.13 判据 v2 无字数上限（同人簇条款），115 万字同人长对话（470728，
1473 章 × 716 字）也按 `dialogue` 判出；非同人对话在 15 万字以上无判据

## 6.1 优质短篇的判定（与 `form` 正交，用户 2026-11-18 定）

`form` 只回答"是不是短篇"，**不回答"是不是好短篇"**。用户明确：
目标是**发现优质短篇，不是劣质短篇**；且**不能只靠 favs 推荐**——
短篇在走下坡路，不同世代头部 favs 差一个数量级以上，绝对门槛会系统性误判。

### 6.1.1 三条实测依据（本地 `out/novels.csv` + `eras` 现算）

1. **字数分不开优质与劣质**：短篇（≤5万）按 favs 分层，favs<5 档字数 P25/P75=
   2,380/9,398，favs≥2000 档 P25/P75=18,904/26,887——有重叠，区分靠的是 favs（口碑）
   本身，不是字数。所以**不能用调整字数边界来筛优质**。
2. **劣质书污染统计，中位数失真**：短篇 ≤3万 共 176,756 本，favs 中位数被拉到个位数；
   其中"已完结 + favs<5 + 字数<8千"的疑似**伪完结劣质书 10,297 本，占已完结短篇 33.7%**，
   收藏总和仅 14,205。用户指出：这类"没完结强行改完结"的书本身就是劣质，
   优质短篇 favs 是它们的**几个数量级**（P90=91、P95=180、P99=531，头部>2000），
   用中位数描述这个池没有意义。
3. **绝对 favs 跨世代不可比**：短篇（≤5万）头部随世代剧烈波动——
   favs P99 从 2012 年 **79** → 2020 年 **1,081**（13 倍），favs≥100 占比从 1%→14%。
   设绝对门槛（如 favs≥50）必然偏向 2020 前后那批、埋没早期优质短篇。
   这正是报告 02/08「累计指标混杂书龄与曝光」与双模式契约 §3.2 信号白名单的立论。

### 6.1.2 判定规则（面向推荐层，非 `form` 字段）

- **优质 = 同代高口碑分位**，用 `fav_pctl`（在 `est_year` 世代内、对完整 universe 计算的
  收藏分位），**不用绝对 favs 设门槛**；`pr`/`pctl_pr` 作辅助（口碑效率）。
- 绝对 favs 只作**展示锚点**（详情页"收藏 531 / 同代分位 99.2%"并列，见契约 12 §7.3），
  **严禁**回流推荐打分（契约 12 §3.2 白名单红线）。
- 候选池门槛仍守 `favs ≥ 10`（PR 可算、分位稳定，报告 21），但这是**可靠性下限**，
  不是"优质"标准；优质由同代分位高低决定。
- **伪完结劣质书**（已完结 + favs<5 + 字数<8千一类）不进优质候选池；
  是否整行从种子剔除另案评估（当前只做推荐层过滤，不动 `books` 行）。
