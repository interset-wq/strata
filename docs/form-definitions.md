## 1. 结论

- `form` 是**互斥单值标签**，只作榜单过滤，**不参与任何分位计算**；分位五列（分母=完整 universe）与 D2 `deep_ranks` 不动。
- 六值靠**逐级覆盖**实现互斥单值，最高优先级是用户直接裁定（级 -1），其次是 IP 封闭名单（级 3）。
- **种子 form 已无估计值**：100% 来自 DOM 事实 + App 官方产品线标记（E.24 / E.28）；**universe form 仍是规则估计**（含覆盖到的 `categoryId`），误差率见 §5，凡按 form 分组的 universe 统计都须标注「形式为推断」。
- 用户裁定压过一切判据；数据出众的书判错代价最大（会排进错误 tab），逐本问人比再爬一遍便宜。

上游依据：09 附录 D、报告 22（对话识别）、报告 06 §4（征文命名）、契约 12 §6。

## 2. 定义与判定

### 2.1 字段契约

```
books.form TEXT NOT NULL CHECK (form IN
  ('invalid','short','medium','long','dialogue','ip_collab'))
CREATE INDEX idx_books_form ON books(form, favs DESC);   -- schema v2→v3，24→28 列
```

- `validate.py` 断言取值域并统计分布，记入 `manifest.json`；引擎榜单/发现流端点接受 `form` 过滤参数（契约 12 §6），UI 须标注「形式为推断，非官方分类」。

### 2.2 判定优先级

从字数兜底开始，高优先级判据依次覆写：

| 执行顺序 | 级 | 判据 | 性质 | 覆写值 |
|---|---:|---|---|---|
| 1 | 0（兜底） | 字数切档（含 invalid 下界） | 估计 | `invalid/short/medium/long` |
| 2 | 0.5 | 正文征文否决对话形态（§2.3） | 确定性 | 保持字数档（仅中篇档） |
| 3 | 1 | 对话形态判据 v2（§2.3） | 估计（章节真值校准） | `dialogue` |
| 4 | 1.2 | 详情页 DOM 的**散文**证据（§2.3） | 确定性（产品线声明） | 撤销级 1，回到字数档 |
| 5 | 1.5 | 短篇点击天花板（§2.4） | 确定性（App 目验） | `invalid` |
| 6 | 2 | 对话征文标记（§2.3） | 确定性 | `dialogue` |
| 7 | 3.5 | 详情页 DOM 的**对话**证据（§2.3） | 确定性（产品线声明，优先于征文组别） | `dialogue` |
| 8 | 3.6 | App 官方 `categoryId=1/4`（§2.5） | 确定性（App 产品线标记，仅正向） | `dialogue`，可救回 invalid |
| 9 | 3 | IP 合作封闭名单（§2.6） | 确定性 | `ip_collab` |
| 10 | **-1（最终）** | **用户直接裁定**（§2.5） | 确定性（人工目验） | 任意值，末尾整体覆写 |

`级` 是历史编号，不代表表中先后；实际按“执行顺序”逐级覆写。`-1` 在 `classify()` 末尾整体覆写，压过一切；`3` 是**自动判据中最高**（IP 名单最后覆盖），与对话实测零交。

优先级要点：

- **用户裁定压过一切（E.27）**：数据出众的书判错代价最大（头部书会被排进错误的 tab），这类书很少，逐本问人比再爬一遍便宜。
- **对话高于篇幅**：对话每章约 500 字、整本可长（锚点 88 万字），先按字数切会把长对话排进长篇榜——这正是 form 要消除的噪声。
- **IP 自动判据置顶**（除用户裁定外最高）：名单封闭、确定性最高，与对话/短篇实测零交。
- **DOM 两级插入（E.22，用户定）**：对话/互动小说不支持 Web 阅读，详情页预读区只放产品声明、散文页放正文首段；故「DOM 有正文」撤销一切形态估计（级 1.2），「DOM 是对话声明」直接判对话并覆盖征文组别（级 3.5）——产品线事实优先于投稿赛道。
- **级 1.5 只作用于仍为 short 的书**：判据 `words ≤ 5万 且 clicks > 215,723`，即「越过真短篇点击上限却还在短篇档」——僵尸或假短篇，归 invalid；级 1 已判 dialogue 的越线书不受影响。
- **级 1 不得救回 invalid（E.13）**：僵尸书章节数极少、ckw 天文高（4166：775 字 ckw=13.2），形态估计会误翻僵尸（实测 2,405 本）；只有级 2/3 确定性证据可以救回。
- **征文名不定篇幅（E.12，红线）**：`contest` 含「短篇/中篇/长篇」一律不覆盖字数——征文名只反映投稿赛道（86279「少女与龙」挂五征短篇却 13.9 万字、641618 挂十一征中篇却 129 万字）；对话征文与 IP 名单是确定性身份，照常覆盖。

### 2.3 对话/互动判定 `dialogue`

字数边界（2026-11-27 起）：`invalid < 2,000 ≤ short ≤ 34,999 < medium ≤ 150,000 < long`；短/中切点按**万字四舍五入到整数 = 3 属短篇**的用户口径（保留 0 位小数是 3 就算 3 万），即 `round(words/10000)==3` → 34,999 字为短篇上限、35,000 起归中篇。此前 5 万切点已废止。2026 官方新口径「15 万单切点」仍不采用。此切点同时驱动对话判据的短篇档上界（`dialogue_form.FAN_MAX_WORDS/IP_MAX_WORDS=34_999`、`PROSE_CONTEST_MIN_WORDS=35_000`）与分档分类器 BANDS。

**级 3.5 详情页 DOM 证据（确定性，E.22，目前最强形态证据）**：对话/互动小说不支持 Web 阅读，PC 详情页预读章节区 `.chapter-info .chapter-content` 只放一行产品声明（「全新的对话小说版本…」/「全新的沉浸式互动小说…」），散文同位置是正文首段。命中「对话小说 / 互动小说」即判对话，反之（有正文）撤销级 1 估计。真值表 `analysis/anchors/web_dialogue.jsonl`（中篇种子 944 本：363 对话 / 558 散文 / 22 无正文 / 1 已下架），抓取脚本 `fetchers/probe_web_dialogue.py`。产品线声明优先于征文组别（`ckw` 对中篇档近乎失效：363 本 DOM 对话 `ckw` 中位仅 2.71、最低 0.02，按 `ckw` 只能抓到 8%；章节命名会漏 4 本沉浸式互动小说）。自洽校验：363 本 DOM 对话全部 `nid ≥ 83,818`，零例外。

**级 1 代理口径（仅作交叉校验，不作判据）**：App `GET /novels/{id}/chaps` 的章节计数单位——对话书「第 N 话」、散文「第 N 章 / 序章」。中篇 944 本实测「话」359 本与 DOM 一致，但有 3 本叫「话」而 DOM 有正文（550853 / 576854 / 16668）、4 本互动小说叫「章」，故只在复核表留 `unit_evidence` 列。

**级 2 征文标记（确定性）**：`contest` 含「对话」或「点鸭」＋用户 App 目验核实的 7 个征文（`怪谈异闻主题征文长篇`、`春节征文长篇`、`穿越主题征文`、`星穹小说家征文`、`春节征文短篇`、`战斗主题征文`、`怪谈异闻主题征文短篇`），确定集约 12,286 本（快照现算）。

**级 1 形态判据 v2（估计，E.13 R18 + E.16 天花板 + E.17 同人 + E.18 时间下界与 IP 标题；用户裁定、章节真值校准）**，七条款取 OR、全部受 `nid ≥ 83,818` 时间下界约束：

| 条款 | 条件 |
|---|---|
| ① | 同人（`genre=同人` 或 tags 含同人）且 `price_type ∉ {VIP,签约}` 且 `words ≤ 20,000` |
| ② | 同人且 `ckw ≥ 6`（无字数上限） |
| ③ | 非同人且 `words ≤ 34,999` 且 `ckw ≥ 13` |
| ④ | 非同人且 `34,999 < words ≤ 150,000` 且 `ckw ≥ 30` |
| ⑤（E.16） | `words ≤ 34,999` 且 `clicks > 215,723`（不限同人/签约） |
| ⑥（E.17） | 同人且 `words ≤ 34,999`（不看 `ckw`、不看签约） |
| ⑦（E.18） | 标题含米哈游 IP 词且 `words ≤ 34,999` |

- `ckw` = 快照 `clicks ÷ words`：同字数下对话章节多、曝光互动天然更高。校准（n=193，真值=章节中位字数≤1100）：精确率 0.92、召回 0.85；`ckw < 3` 实测 0 对话。
- **时间下界（E.18，硬约束）**：对话体 2017-07 才上线，形态条款只在 `nid ≥ 83,818` 生效（回退 1,709 本早期书，其中 1,664 本 2007–2017 传统同人短篇）；征文标记（级 2，确定性）不受下界约束。证据：历史月榜对话月票榜首月为 2017-07，此前十年零对话征文标记。
- **正文征文否决（E.21，用户定）**：七条款在中篇档（3.5–15 万字）内不适用于带非对话征文标记的书（受影响 8 本由对话改判中篇）；短篇档不受影响（同人征文仍按 E.17 判对话）。
- **条款⑤（E.16）依据**：用户目验「回到旧时光」clicks 215,723 为真短篇点击上限（36 本误判短篇全部 >226k），专收 ckw 6–13 灰带的高曝光对话文，universe 净增 155 本对话。
- **条款⑥（E.17）依据**：种子 short 层 170 本同人逐一目验全部误判——头部十余本为崩坏/综漫/型月系、20 万点击、3–4 万字、ckw 5.2–6.3 恰卡在②阈值 6 之下（②在种子内命中 0 本、事实上空转）；同人区是对话/互动主场，故对同人改按字数额度判形态。
- **条款⑦（E.18）依据**：标题含米哈游 IP 词是对话同人强特征但只覆盖头部、属级 1 估计；限 `words ≤ 3.5 万`（同字数 medium/long 的 IP 书 ckw 中位仅 1.33/0.95，是正常散文长篇）；universe 内约 1,745 本 short 由⑦翻为对话。
- **三条天花板（全时期有效，E.17 固化、E.19 升级为判定，P7 守门）**：常规池 short 层 `clicks ≤ 215,723`（回到旧时光）、`favs ≤ 5,478`、`praises ≤ 2,389`（听雨）。越线的书经 App 目验不是短篇（内容被替换的僵尸或作者恶意标完结的长篇），归 `invalid`；故 P7 断言不加时间下界，常规池 short 层零越线。**E.41 例外**：强制白名单（获奖/人工）在 form 层豁免 E.19 点击天花板——43380《早安 哥哥 喵》三征短篇铜奖 clicks 292,057 / favs 5,924 是真短篇天花板，按字数判 `short`，走白名单数据分流入种，不计入 P7 的常规池断言。获奖证据强于点击启发式。
- **残差**：章均 1100–1250 字边界书两可；非同人 >15 万字无判据，接受该召回缺口。
- **作者维度不作判据（E.23 实测，120 本跨档抽样）**：同一作者形态不一致（有对话征文标记的作者名下 short 仅 28%、medium 60%、long 32% 是对话，基线 7%；秋米拉 7 本横跨 long/short/dialogue）。作者信号只有 4–8 倍 lift，作特征可用、作传播规则会把 4,000+ 本散文误判。**form 是作品级属性，禁做作者级传播**。
- **字数不判形态**：形态条款的字数上限只用于群体估计，禁止用它否定确定性证据认出的长对话；级 1 不得救回 `invalid`（E.13）。

### 2.4 `invalid`（僵尸 / 假短篇）

两类，均无收录资格：

1. `words < 2,000` 且未被级 2/3 救回。2000 = app 正常章节字数下限，<2000 几乎都是目录抓取残缺的僵尸。
2. `words ≤ 34,999` 且 `clicks > 215,723`（E.19）。越线者不是真短篇：内容被替换成无意义文本的僵尸或作者恶意标注完结的长篇；字数、状态、点击三者都不可信，故不判 long。级 1 对话命中优先。**E.41 白名单豁免**：`forced_admission_nids()`（获奖 + 人工强制入种锚点，与 `seed_policy` 共用）中的书跳过本条，按字数正常判形态——否则真短篇天花板 43380 会被判 invalid 后失去短篇榜排名。这是 form 判定与质量筛选的解耦：作品级形态不被种子收录启发式污染。

`form` 标签不随 status 变；收录层剔除、无任何豁免（P6 守门，入种恒 0）。本数见 §5。

### 2.5 用户裁定通道（级 -1，E.27）与 App `categoryId`（级 3.6，E.28）

**用户裁定通道（级 -1，E.27）**

- 文件：`analysis/anchors/form_user_verified.jsonl`，一行一本，字段 `nid` / `form` / `reason` / `verified_on`；文件不存在 = 不干预。
- 加载：`lib/forms.py::user_forms()`（`lru_cache`）→ `classify()` 末尾整体覆写，优先级高于 DOM、征文与 IP 名单。
- 用法：用户点名某书形态有误 → 追加一行 → 重跑 `build_seed.py`（P 断言照常校验；若裁定与 P6/P7/P8/P9 冲突，说明裁定本身需复核，不许绕过断言）。
- 不做的事：不因裁定扩大爬取、不加启发式；裁定是终点不是训练集（E.23/E.24 已证明跨档/作者传播会大规模误判）。

**App `categoryId` 正向判据（级 3.6，E.28）**

- 判据：`cat=1`（对话小说）或 `cat=4`（沉浸式互动小说）→ `dialogue`，可救回 `invalid`。锚点 `analysis/anchors/app_categories.jsonl`，`lib/forms.py::app_categories()` 加载。
- **只正向、不反向**：`cat=0` 不撤销 dialogue（早期对话书约 5,666 本仍是 cat=0，反向撤销会毁掉一半对话库）；`cat=3` 是征文赛道，不据此判形态或篇幅。
- **覆盖边界**：App API 快照只覆盖约 45% 的书（随版本变化），缺席不作推断；故本判据大幅收敛误判，但不是全库金标。
- 效果：universe 中 `cat=1/4` 的误判清零；种子重建救回 241 本被形态资格挡在门外的 cat=1 对话书（`seed_version` → 20260503.24）；随后 P10 假完结剔除再清掉 145 本 short/medium（→ 20260503.25，见 `fake-complete-short-medium.md`）。

### 2.6 其余三值

- **`short`（2,000–34,999 字）**：1 万–3.5 万未成形作品归 short，不设 tiny 档。短篇只是形式不是质量（旧 ≤5 万池中「已完结 + favs<5 + 字数<8千」的伪完结劣质书占已完结短篇 33.7%，该比例为旧口径快照），优质判定见 §6。
- **`medium`（35,000–150,000 字）**：官方 2026 已取消中篇档，但榜单过滤必须保留——并入短篇会让 favs Top200 里 197 本是中篇、真短篇永无推荐位（09 附录 D §D.1）。
- **`long`（>150,000 字）**：长篇榜须排除 `dialogue`（form 核心收益）。
- **`ip_collab`**：判定 = `contest` 精确命中六类封闭名单（楚楚动仁、崩坏3、少女前线、龙之谷、失业魔王、英雄再临），集中 2016–2019，无需启发式。标题 IP 词（芙宁娜/钟离等）是同人对话特征、不是 IP 合作；「超新星杯」是短篇赛事，按字数归 `short`。

## 3. 操作：种子收录资格

`classify` 产出纯标签、不随 status 变；收录资格在种子层判定：

```python
def seed_admit(row, form, exempt_complete, exempt_contest, blacklist, pool) -> bool:
    if row.nid in blacklist:
        return False                                  # E.32 黑名单优先于一切豁免
    if row.is_licensed:
        return True                                   # 授权日轻展示例外（用户裁定）
    if form == "invalid":
        return False                                  # 僵尸，无豁免（P6）
    if form in ("short", "medium"):
        if row.status != "已完结" and row.nid not in exempt_complete:
            return False                              # E.31：仅人工清单可豁免
        if row.nid not in pool and row.nid not in exempt_contest:
            return False                              # E.34：赛事 union 正向准入
    return True
```

- **弃书规则（E.11 → E.31）**：短/中篇阅读本质是「一口气读完」，连载中视为作者弃书，丧失收录资格。**所有年份同受此硬约束**；2026 起 sfacg 又把中篇并入短篇，更无年份例外。范围是非授权种子；授权日轻 47 本仅作展示、不进评分/收录池，按用户裁定保留（其中 2 本连载中篇）。

## 5. 边界

### 5.1 优质短篇判定（与 form 正交，推荐层用）

`form` 只回答「是不是短篇」，不回答「是不是好短篇」。判定规则：

- **优质 = 同代高口碑分位**：用 `fav_pctl`（`est_year` 世代内、完整 universe 分母），**严禁绝对 favs 门槛**——短篇头部 favs 跨世代差 13 倍（P99 从 2012 年 79 → 2020 年 1,081），绝对门槛系统性偏向后期、埋没早期优质短篇。
- `pr`/`pctl_pr` 作辅助；绝对 favs 只作详情页展示锚点，禁止回流推荐打分（契约 12 §3.2）。
- 候选池可靠性下限 `favs ≥ 10`（PR 可算，报告 21）；伪完结劣质书（已完结 + favs<5 + 字数<8千一类）不进优质候选池，整行剔除裁定见 `fake-complete-short-medium.md`。
- 长篇区排序信号是 `lqs`（篇幅加权口碑分，见 `length-weighted-quality.md`），与优质短篇判定均接入契约 12 §3.2 白名单。

依据（本地现算，快照）：① 字数分不开优质与劣质（favs<5 档字数 P25/P75 = 2,380/9,398，favs≥2000 档 = 18,904/26,887，有重叠）；② 劣质书拉扁中位数（≤3 万短篇 favs 中位数个位数；伪完结劣质约 1 万本收藏总和仅约 1.4 万）；③ 短篇在走下坡路，必须世代归一才能让各代头部进入候选。

### 5.2 已定边界事项

- **2000–1 万字归 short**（用户定），<2000 归 `invalid`；不设 tiny 档。
- **互动不单列**，并入 `dialogue`；详情页 DOM 能区分两种文案（「对话小说」/「沉浸式互动小说」），但用户口径是同一产品谱系，六值不加第七值。
- **对话 vs 篇幅交叠**（对话征文∩短篇命名 484 本、形态∩短篇命名 375 本）一律按优先级归 `dialogue`，无需抽样复核。
- **IP 名单封闭**，无待抽样项。
- **种子 form 已无估计值；universe form 仍规则估计、须标注推断**——产物与 UI 须标注「形式为推断，非官方分类」。
