# 中篇口碑分 `mqs`（5–15 万字）

> **定位**：本文是中篇区排序分 `mqs` 的唯一权威口径——公式、常量、校准结论、边界仅在此维护。
> **状态**：2026-11-19 设计稿、参数已定案，**归档不落地**（app 主线为经典模式、暂不引入新指标）；未落代码、未进种子、未进引擎，待量化模式进入施工时再启动，届时无需重跑调参。工程侧，本文不执行。
> **权威范围**：本文唯一维护 `mqs`；`lqs` 的定义与边界见 `length-weighted-quality.md`。两域是同指标不同域、分数不可比、不合并，中篇不直接复用 `lqs`。
> **口径**：所有池规模、相关系数、篇幅数字均为快照现算值（`analysis/probe_medium_signal.py` 现算），随种子版本变化，仅供参考，禁止硬编码进代码。
> **更新日期**：2026-11-21。

## 1. 结论

```
mqs = q × (0.75 + 0.25 × mlen)
mlen = log(字数 / 5万) / log(15万 / 5万)      # 夹在 [0, 1]
```

**与 `lqs` 同一个公式、同一个篇幅权限 `K=0.25`，只把篇幅锚点从 15 万–100 万移到 5 万–15 万**，并加一条更高的证据下限（`favs ≥ 300`）。`q` 的定义不变（世代 × 收藏档内 `pr` 分位）。

---

## 2. 为什么不能直接用 `lqs`

中篇字数全部 < 15 万，`lqs` 的 `len` 恒为 0 → 所有中篇被压到 `0.75` 下界，等价于「按 `q` 排、篇幅无信息」。而 `q` 单独用会把推荐池压到 9.7 万字（−10%）——中篇池 5–7.5 万有 1,143 本、12.5–15 万只有 391 本，短端数量压倒性占优。

中篇还有两个 `lqs` 没遇到的问题：

**① `pr` 被收藏规模支配得更狠。** 中篇 10–50 收藏档 `pr` 中位 1.33、5k+ 档 0.16，且 10–50 档 p90 高达 3.18（赞是藏的 3 倍），所以证据下限必须高于长篇的 200（快照现算）：

| 收藏档 | 本数 | `pr` 中位 | `pr` p90 |
| --- | ---: | ---: | ---: |
| 10–50 | 1,270 | 1.333 | 3.184 |
| 50–200 | 872 | 0.743 | 1.926 |
| 200–1k | 562 | 0.439 | 1.115 |
| 1k–5k | 96 | 0.270 | 0.495 |
| 5k+ | 6 | 0.159 | 0.349 |

**② `pr` 的世代漂移比长篇严重一个量级。** 池内 `rho(pr, est_year) = -0.46`（2019–2020 中位 0.49–0.54，2025 只有 0.17）。世代归一是**必需**的，直接决定 `MIN_CELL` 的取值（§4③）。

## 3. 定义与常量

| 常量 | 值 | 理由 |
| --- | --- | --- |
| `ZONE_FORM` | `medium` | 只作用中篇区；`short` / `dialogue` / `ip_collab` 不适用 |
| `ZONE_WORDS` | 5 万 < 字数 ≤ 15 万 | 与 `forms.MEDIUM_MAX_WORDS` 一致；两个边界都是硬约束 |
| `REQUIRE_DONE` | `status = 已完结` | E.20：连载中篇零入种，不构成推荐池 |
| `EVIDENCE_MIN_FAVS` | **300** | 中篇 `pr` 在 300 以下被小样本支配（§2①）；500 会退化成 `pr` 榜 |
| `PR_CAP` | 5.0 | 沿用 `lqs` 的长尾截断 |
| `MED_LO / MED_HI` | 5 万 / 15 万 | `mlen` 的 0 → 1 锚点，即中篇域本身 |
| `LEN_K` | **0.25** | 与 `lqs` 同常数（是校准结果，见 §4②） |
| `BANDS` | 300 / 1k / 5k | 收藏档；与 `lqs` 的 200 起不同，因为下限抬到 300 |
| `MIN_CELL` | **10** | 世代 × 档最小样本；池小、门槛越高世代偏差越大（§4③） |

- **质量项 `q`**：把 `pr` 按收藏档切开，再在「世代 × 档」内取分位；「世代」用 `est_year`（与 `lqs`、分位五列同源），不另造世代段——实测 4 段合并反而更差（`rho(mqs, year)` 从 −0.05 恶化到 −0.09，最小 cell 掉到 1）。
- **篇幅项 `mlen`**：对数插值，锚点就是中篇域两端；`≤5 万` 归 0、`≥15 万` 归 1。
- **合成**：乘性、下界 0.75，与 `lqs` 相同——篇幅最多左右 25% 的分，低 `q` 的书永远起不来。

## 4. 校准结论（三个常数均为实测，快照现算）

### ① 证据下限：300

扫不同下限，看 Top-100 收藏中位与口碑保真度：

| 下限 | 池 | Top100 收藏中位 | `rho(mqs, favs)` | `rho(mqs, pr)` |
| ---: | ---: | ---: | ---: | ---: |
| 100 | 1,102 | 213 | -0.10 | 0.72 |
| 200 | 664 | 320 | -0.07 | 0.78 |
| **300** | **420** | **441** | **-0.15** | **0.71** |
| 500 | 224 | 904 | -0.05 | 0.97 |

300 是拐点：再低推荐头部会变成「收藏 200 出头的小众书」；500 则 `rho(pr)` 冲到 0.97，退化成纯 `pr` 榜。**不需要再加 `praises` 分子下限**——`favs ≥ 300` 已隐含分子规模（`praises ≥ 100` 只砍 59 本，不值得损失覆盖率）。

### ② 篇幅权限：`K = 0.25`

对齐目标沿用 `lqs`：推荐池 top100 中位篇幅 = 池的收藏加权中位篇幅（本池约 10.8 万字）。

| `K` | Top100 中位篇幅 | 与加权中位差 | `rho(mqs, favs)` | `rho(mqs, pr)` |
| ---: | ---: | ---: | ---: | ---: |
| 0.05 | 97,729 | −9% | -0.18 | 0.73 |
| 0.10 | 101,961 | −5% | -0.17 | 0.72 |
| 0.20 | 104,870 | −3% | -0.16 | 0.71 |
| **0.25** | **107,793** | **−0%** | **-0.15** | **0.71** |

中篇只差 3 倍篇幅却仍需 0.25——要压制的不是「幅度」而是「数量」：短端书是长端书的 3–5 倍，池子天然向短端倾斜。这是校准结果，不是把长篇参数照搬。

### ③ 世代门槛：`MIN_CELL = 10`

`rho(pr, est_year) = -0.46`，世代必须归一；但池小（约 420 本 ÷ 19 世代 ÷ 3 档 ≈ 7 本/cell），门槛稍高就会大面积回退到「全档分位」、世代偏差立刻回来：

| `MIN_CELL` | Top100 中位篇幅 | `rho(mqs, favs)` | `rho(mqs, year)` |
| ---: | ---: | ---: | ---: |
| 5 | 107,932 | -0.13 | -0.02 |
| **10** | **107,793** | **-0.15** | **-0.05** |
| 20 | 107,656 | -0.17 | **-0.21** |
| 30 | 107,656 | -0.17 | **-0.23** |

方向与直觉相反：**门槛越低、世代偏差越小**。取 10 是「小 cell 分位噪声」与「不回退」的折中（cell=10 时档内分位分辨率 10%，可接受）。

### ④ `K` 不是过拟合：两条独立检验

- **bootstrap（池内重抽 400 次求最优 K'）**：

  | 统计量 | 值 |
  | --- | ---: |
  | K' 中位 | 0.24 |
  | K' P25–P75 | 0.16–0.30 |
  | K' P10–P90 | 0.06–0.38 |
  | `K = 0.25` 位置 | 56% 分位 |
  | `\|K' − 0.25\| ≤ 0.05` 占比 | 47% |

  `K=0.25` 落在分布中心而非尾部——420 本池子虽小，校准目标本身没把 K 推偏。校准目标随池口径有系统性梯度（全部中篇约 9.7 万字 → 已完结约 10.0 万 → 评分池约 10.8 万 → 种子约 11.0 万），但都在 10 万字量级，不改变 K 的量级（快照现算）。
- **行为弹性（20,214 本含连载）**：同代 × `pr` 五分位格内回归 `log(favs) ~ log(words)`，斜率中位 β=0.49，5 万→15 万对应收藏 1.71 倍；按系数反推若要追平读者偏好 `K` 应取 0.41。**但刻意不采用**——`K≈0.41` 时 Top100 中位篇幅过冲约 +6%，用先验替代代表性、与 `lqs` 立意相反。记录 0.41 作**上界**：中篇对篇幅的奖励可以到 0.4 而不崩，0.25 是对齐目标给出的最优解。

### ⑤ 已排除的调参项（负结果，勿重做）

`praises ≥ 20/50/100` 分子下限（不必要，`favs ≥ 300` 已隐含）；两级世代回退（`rho(year)` −0.05→−0.04，收益不抵复杂度）；世代分 4 段（恶化到 −0.09、最小 cell 掉到 1）；`MIN_CELL` 提到 20/30（反向恶化到 −0.21/−0.23）；经验贝叶斯收缩 `pr`（不够狠则更冷门、够狠则退化）。

## 6. 边界

- **`favs < 300` 的中篇不给分**（`mqs = NULL`，回退 `fav_pctl` 排序）。种子层约 578 本已完结中篇里约 51% 可评分（快照现算）——这是刻意的：`pr` 在 300 以下不可信，给分等于把噪声排进推荐位。
- **只作用于中篇**：`short` / `long` / `dialogue` / `ip_collab` 一律 `NULL`。长篇继续用 `lqs`，两者域不重叠、**不要合并成一个分**（锚点不同，分数不可比）。
- **不作质量标签**：详情页只展示「9.4 万字 / 同代口碑分位 88%」，不给「好/差」。
- **池会变**：420 本为快照示例，随种子增删、E.20 规则变动而改变，须现算。
- **不解决中篇池子小的问题**：中篇高收藏书天然少（完结中篇里 5k+ 只有 6 本），任何口碑信号都会比长篇更偏小众——这是平台结构，不是公式缺陷。

## 8. 不做什么

- 不改 `lqs` 的定义、锚点、`K`；两套分只共享公式形状。
- 不改 `pr`、不改分位五列与其分母、不改报告 23。

- 不把 `mqs` 用到短篇/长篇/对话区，不写进 `books.form` 的判定链。
