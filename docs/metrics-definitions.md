# 全局文档：自定义指标定义

> **定位**：本项目所有自定义指标（非 SFACG 官方字段）的唯一权威定义，报告、App、推荐层口径以本文为准。
> **状态**：已定案口径集；新增或修改指标须同步改本文与生成器，不修改报告、定年体系与既有 App 设计文档。
> **权威范围**：本文唯一维护——基础维度（定年/universe）、五个分位列、派生口径、推荐层信号白名单的职责与红线；具体指标的完整公式在校准域文档。
> **口径**：所有规模数字、上界、误差均为快照现算值，随数据版本变化，仅供参考，禁止硬编码进代码。
> **更新日期**：2026-11-21。

## 1. 结论：三条红线

官方 `genre` 只按主题分 9 类，不提供分位、世代、口碑效率等分析指标；本文把「跨世代可比地找书」所需的自定义指标集中钉死，避免同名不同义（最典型的坑：本项目 `pr` 是**赞藏比**，而 App API `point` 是 0–10 评分，两者无关）。

1. **累计指标跨时点不可比**：`favs/clicks/praises` 是快照累计值，混杂书龄与曝光分母；比较必须限定在同一世代/同一时点。
2. **快照态 ≠ 当期态**：`books.status/price_type` 是上界态，不是「现在是否连载/签约」。
3. **累计值不回流推荐打分**：平台累计值（尤其 `clicks`）只作展示，推荐信号走分位与口碑效率白名单，防马太效应后门。

原始官方字段语义见 `sfacg-app-api.md`、`sfacg-endpoints.md`；物理存储见 `app/docs/02-data-model.md`；小说形式 `form` 见 `form-definitions.md`。

## 2. 基础维度

### 2.1 `est_year` / `est_date` / `est_conf`（定年）

- **定义**：由 `lib/eras.estimate(nid)` 在锚点表上的 `log(nid)` 分段线性插值给出。锚点 281 个（91 API + 12 用户核实 + 1 征文页 + 177 E.15 app_api 月榜遗漏书，2026-11-19 并入）。
- `est_year`：上架年估计（整数），是**分位与世代榜的分组键**；`est_date`：日期 `YYYY-MM-DD`。
- `est_conf` 四档：`exact`（锚点书——`est_date` 即 App API `addTime` 官方值、非估计，随锚点追加自动扩大）、`high`/`mid`/`low`（内插，锚点间隔 ≤90 / ≤365 / 更远天）；外推一律 `low`。
- **精度（快照现算）**：锚点区内插段对第三方 `published_at` 交叉校验 31,229 条，误差中位 2 天、P99 9 天；留一法内插段 p90 3 天 / 均值 5.1 天；**外推段（nid > 788,076）误差 132–153 天，不可用**。
- **`20XX萌神`（2018–2024）是年度荣誉，年份=届次，严禁用于定年**。
- 定年体系是大量分析的基座，**不得因单点旁证整体替换**：`addTime` 只在命中该书自身时给 `exact` 档（曲线不动），不做全库外推；批量实测锚点（如 E.15 月榜遗漏书）才并入曲线本身。
- 锚点密度的调整策略与外推段维护见 `anchor-density-strategy.md`；定年阈值/外推边界以本文为准。

### 2.2 `universe`（统计参照系）

- **定义**：`is_licensed=0` 且 `est_year ∈ [2007, 2025]` 的全库行，当前约 241,864 行（快照现算）。2026 年为右删失样本、排除；正版日轻 47 本剔除。
- 这是**所有分位的分母**。种子 `books` 只是它的精选子集（当前约 1.9 万本），**在种子池内重算分位会改分母、得到错误值**。

## 3. 分位指标（`*_pctl`）

### 3.1 统一算法

对每个指标 `x`，在 `universe` 内**按 `est_year` 分组**计算：

```
pctl(x) = rank(x, within=est_year, method=average) / group_size
```

- 取值 `(0, 1]`，**1.0 = 该世代最强**；存 REAL，不存档位。
- 空值/不满足前置条件的行置 NULL（不参与、不计入分母）。
- 分母是**完整 universe 的该世代行数**，不是种子池。

### 3.2 五个分位/比率列

| 指标 | 定义 | 前置条件 | 空值规则 |
| --- | --- | --- | --- |
| `fav_pctl` | 收藏 `favs` 的世代内分位 | — | 无分母世代为 NULL |
| `click_pctl` | 点击 `clicks` 的世代内分位 | — | 同上 |
| `praise_pctl` | 点赞 `praises` 的世代内分位 | — | 同上 |
| `pr` | **赞藏比** `praises / favs` | `favs ≥ 10` | `favs<10` 置 NULL（避免小分母抖动） |
| `pctl_pr` | `pr` 在世代内的分位 | `pr` 非空 | `pr` 为 NULL 则为 NULL |

> **命名陷阱**：`pr` 在本项目**永远是赞藏比**（praises/favs），不是评分。App API 的 `point`（0–10 评分）与本字段无关，**禁止用它覆盖 `pr`**。2026-11-18 定案：`point`（读者水军刷差评，作者要求官方删除，样本 2020 年后 90.9% 为 6.0、2021+ 为 93.5%）为废弃字段，采集层直接丢弃；取值比例见 `api-field-mapping.md`。

### 3.3 用途与边界

- 分位是「跨世代可比地找书」的核心：绝对 `favs` 差几个量级，分位把每本书放回自己世代的相对位置。
- **优质判定用同代分位**：优质短篇 = 高 `fav_pctl`，**严禁绝对 favs 门槛**（短篇 P99 跨代 79→1081 差 13 倍，绝对门槛系统性偏向早期）。
- 候选池的 `favs ≥ 10` 是可靠性下限（PR 可算、分位稳定），不是「优质」标准。
- `form` 只是分类标签，**不参与任何分位计算**，分母恒定。

### 3.4 `lqs`（篇幅加权口碑分，长篇区排序信号）

- **职责**：长篇区（`form=long` 且 `words>15 万` 且 `favs≥200`）的**排序分**；用「世代 × 收藏档」内 `pr` 分位乘一个有界篇幅先验 `[0.75, 1.00]`，防止推荐池被压到 20 万字量级。其余情况为 NULL。
- **性质**：秩相关与收藏 −0.01、与 `pr` +0.62——是口碑榜不是热度榜；**只作排序信号，不作质量标签**，展示层沿用 §3.3 的分位并列口径。
- **权威口径、公式、常量、校准与边界只在** `length-weighted-quality.md`；实现 `analysis/lib/lqs.py`。中篇域 `mqs` 见 `medium-quality-score.md`（与 `lqs` 同指标不同域、不合并）。

## 4. 派生口径指标

- **世代（generation）**：按 `est_year` 划分的年度队列；跨书比较默认同世代内。年度序列止于 2025，2026 右删失不进入分位与世代榜。
- **断更时长**：`updated_at` 减内容上界（2026-05-03）。**不可**用 `updated_at` 减 `nid` 定年推算完结时长（low 置信段符号翻转，6,913 本无法分档）。`updated_at` 只当时长、不当时间轴。
- **在架覆盖率（约 69.3%，快照现算）**：报告 10 重写定案——三态判据 + 分母先扣构建剔除 2,451 本 + 按 `nid` 段分层加权，覆盖率 69.3%（95% CI 64.6–73.9）。三态：死亡 = HTTP 200 + 否定文案（「小说不存在」/「出错啦」）；僵尸 = 有详情但无阅读入口或数字非法（`div.book_Catalog` 下无 `<a>`）；存活 = 有详情 + 入口 + 数字合法。只写覆盖率有三态语义歧义，不下发单一值；补爬对象约 1 千本，非 11.1 万。遗漏偏「短、新、更新中」且按 `nid` 段非均匀，凡绝对计数是下界，排序与相对比较稳健。
- **生命状态重建**：`books.status` 是快照态；跨时点生命状态须用「已完结且 `updated_at < 该时点`」重建（`report_commercial.attach_done_now()`）。
- **签约 / 商业化**：`price_type`（免费/签约/VIP）是 2026-05 上界态、非当期；月票由充值返还（1 票 ≈ 0.5 元），可投任意书含免费书，热销榜 ≈ 订阅额；`fireMoney` 是按字数计的整本订阅定价、**不是营收**，平台无营收/订阅额/付费人数数据。

## 5. 推荐层信号（双模式契约）

展示层与推荐层**解耦**：用户即使以 novly 模式浏览（展示官方累计值），后台推荐仍统一走量化信号。

- **信号白名单（可用）**：`fav_pctl` / `click_pctl` / `praise_pctl` / `pr` / `pctl_pr` 等同代分位与口碑效率信号，以及长篇区的 `lqs`。
- **红线（禁止回流打分）**：平台累计 `clicks`/`favs` 原始值、书龄、`form` 外的运营位——防马太效应后门（头部永久高曝光）。
- 推荐为**口碑驱动、非协同过滤**（无用户行为日志）。
- 绝对累计值只作展示锚点，详情页并列「收藏 531 / 同代分位 99.2%」。

> **白名单 = 可用信号集，不等于核心指标**；量化模式的 2 个核心指标（排序分 + 位置分）见 `quantitative-mode-metrics.md`。
